# XGE Particle Editor

基于 **C + XGE + XUI** 的原生粒子编辑器，不使用 ImGui。编辑器调用现有 CPU 粒子模拟和渲染器，输出直接兼容 `xgeParticleDefinitionLoad` 的 version 1 JSON / XSON。

## 构建与启动

在已配置 MinGW GCC 的命令行中：

```bat
tools\particleedit\build.bat
tools\particleedit\release\particleedit.exe
tools\particleedit\release\particleedit.exe D:\project\effects\fire.xson
```

构建脚本调用根目录的 `ensure_xge_dll.bat`，然后将匹配的 `xge.dll` 复制到工具的 `release` 目录。可执行程序从自身位置查找 `../presets`，不依赖启动工作目录。分享工具时保留 `release`、`presets` 的相对位置。

当前平台为 Windows，使用系统微软雅黑字体，不复制或分发字体文件。默认窗口 1500 × 960；建议至少 1280 × 800。

## 工作区

| 面板 | 编辑与预览能力 |
| --- | --- |
| 发射器 / 模板 | 添加、复制、删除、重排；静音 / 独奏；七个经典场景模板 |
| 实时预览 | 真实 XGE 粒子渲染；固定种子；播放、暂停、重播、单步、临时手动发射；缩放和平移 |
| 发射器属性 | 分组 PropertyGrid；范围、形状、力场、噪声、颜色、纹理 / 材质名、图集、排序、碰撞、子发射器 |
| 发射时间轴 | 原生 `xuiTimeLineView`；秒刻度 / 60 fps 精度；启动延迟、持续时间、Burst 菱形、播放头回看 |
| 生命周期曲线 / 渐变 | 尺寸、速度、Alpha 三条曲线，以及 RGBA 渐变；图形编辑和精确数值编辑 |
| Burst 表 | 最多 16 个 Burst 的时间和数量；与时间轴同一份数据 |
| 预览设置 | 种子、播放倍率、预览长度、根位置、网格、边界、地面碰撞和移动路径 |

所有面板使用 XUI Dock Panel，可改变停靠位置、合并标签、浮动、自动隐藏和调整尺寸。默认下方面板将时间轴、曲线、Burst 合并为标签；可拖出曲线面板与时间轴同时查看。

布局保存到 `%LOCALAPPDATA%\XGE\ParticleEdit\layout.xson`，与粒子资产分离。损坏或不可读取的布局不会被自动覆盖，使用“重置布局”恢复。带 `--frames` 或 `--exercise` 的测试运行不读写个人布局。

## 推荐操作流程

1. 从左侧选择模板并点“载入”，或打开现有 JSON / XSON。
2. 选中发射器，修改属性；编辑器先用运行时验证候选定义，再提交事务。
3. 暂停并拖动时间轴播放头到关注的时刻。修改参数后，用相同种子从零增量回放到该时刻。
4. 打开“曲线 / 渐变”，调整生命周期变化，再在 Burst 表中调整爆发数量。
5. 通过“绑定纹理”选择图片；在需要时检查预览设置中的地面、移动路径或根位置。
6. 保存粒子定义，游戏直接加载该文件并绑定自己的纹理、材质和碰撞查询回调。

### 时间轴

- 色条表示自动发射器第一轮的启动和持续区间；循环发射器不会在时间轴复制出大量重复条。
- 拖动色条移动启动延迟；拖动其右边缘调整非零持续时间。
- 黄色菱形表示 Burst，拖动修改其相对发射器启动的时间；同一帧多个 Burst 在图上重叠，仍可在表中分别编辑。
- 双击有效发射区间中的空白帧添加 Burst，默认 32 个粒子；双击已有菱形打开 Burst 表。区间外的点击会提示先调整延迟 / 持续时间，不会悄悄将 Burst 放到另一个时间。
- Burst 表的“添加”按播放头位置创建，超出发射区间时使用最近的合法时间；精确时间和数量可直接在表中修改。
- 点击 / 拖动标尺播放头暂停并回放到该帧；键盘左右键逐帧移动。
- `Ctrl + 滚轮` 缩放时间轴。时间轴编辑精度为 1/60 秒，属性表保留更精细的运行时数值。
- 手动 / 事件发射器标注“无固定时段”，不把事件触发误画成确定的发射调度。
- 超过当前预览长度的自动发射区间不显示，不会修改或截短原始定义。

### 曲线和渐变

- 横轴是归一化寿命 `0～1`，不是特效的绝对时间。
- 曲线纵轴是乘法系数，例如 `最终尺寸 = 出生随机尺寸 × 尺寸曲线`。
- 支持线性、阶梯、Hermite 插值；Hermite 的入 / 出切线斜率可在右侧数值编辑，选中点会显示切线方向。
- 双击画布添加点，拖动关键点调整，`Delete` 删除；一次拖拽只产生一条撤销记录，`Esc` 取消拖拽。
- 渐变在棋盘背景显示透明度；拖动颜色点改变时间，右侧使用 XUI ColorPicker 编辑 RGBA。
- 单条曲线 / 渐变最多 8 个点，时间严格递增。清空曲线使用运行时默认系数 1；空渐变为白色。
- “淡出”创建两端线性轨道；“加点”选择当前最宽时间间隔的中点。

### 数值与单位

- 角度、旋转和角速度在界面使用度，在 JSON / XSON 中仍保存运行时需要的弧度。
- 最小随机值不能高于最大值；上调一个范围时可先修改最大值。
- 非零持续时间至少 0.001 秒；Burst 时间必须严格小于非零持续时间。
- 子发射器通过带名称的目标下拉框选择，关闭值为 `-1`；会导致循环引用的目标被禁用，运行时验证仍作为最终检查。
- 删除、重排发射器自动修正引用；这些操作可以整体撤销。

## 模板与资源绑定

提供命中火花、火焰与烟雾、爆炸、雨雪、移动尾尘、魔法光环、UI 彩纸七个模板。模板数据来自 `examples/xge_particles`，不是另一套手写模拟器。加载模板建立一个新的未关联路径文档，不会覆盖模板本身。

`examples/xge_particles/shared_assets.h` 与七个范例共用程序纹理和 ring 材质代码：

| 绑定名 | 编辑器处理 |
| --- | --- |
| 空纹理名 | 默认白色四边形 |
| `soft` | 内置柔边粒子纹理 |
| `sheet` | 内置四帧烟雾 / 火焰图集 |
| 其他纹理名 | 按图片路径加载；相对路径基于当前粒子文件目录，未命名文档基于启动工作目录 |
| 空材质名 | 默认粒子材质，使用发射器混合方式 |
| `ring` | 与魔法光环范例共用的自定义材质 |
| 其他材质名 | 保留原始逻辑名并显示未解析警告，预览暂用默认材质 |

绑定字符串和全部粒子字段原样进入运行时格式，预览不支持的资源不会从文件里消失。资源结构体始终保持稳定地址；重建模拟时先释放渲染绑定，避免悬空引用。可用“重载资源”刷新磁盘上修改过的图片。

“另存为”不改写逻辑资源名，也不复制图片；移动资产到其他目录时，需要同时维护其相对图片路径。真正的项目资源注册表可以在 `pe_preview.c` 的绑定处接入，当前不引入额外的材质资产格式或 Shader 编辑器。

重新生成模板：

```powershell
& tools/particleedit/regenerate_presets.ps1
```

## 保存、撤销与安全边界

- 文档模型与 XUI / GPU 隔离；所有编辑先验证，再入历史。
- 保留最近 64 次修改。连续拖拽以一次事务保存；保存后的撤销、重做仍能正确更新脏标记。
- 新建、打开、加载模板和原生窗口关闭都检查未保存修改；当前编辑框先提交，验证失败时不会切换发射器或继续操作。
- 文件名和内容均按 UTF-8 处理，支持中文路径；文件大小上限与运行时一致，为 1 MiB。
- 同目录唯一临时文件写入、flush 后原子替换目标。失败时不主动删除原文件。
- 覆盖当前文件前比较磁盘内容指纹。发现外部修改、删除或无法读取时拒绝覆盖，要求重新打开或另存为。该检查是保存前冲突检测，不是跨进程协作锁。
- UI 编辑辅助状态、播放头、静音 / 独奏、碰撞测试场景、Dock 布局不写入粒子定义。

## 预览与当前边界

- 模拟使用 1/120 秒固定步长；UI 暂停时停止推进模拟。时间轴单步为 1/60 秒。
- 回放每 UI 帧最多 120 个固定步，并检查约 6 ms 的时间预算。长距离 seek 分帧完成，显示“回放中”，不是一次阻塞式预热。
- 单文档、单预览实例；预览长度可设置为 1～60 秒，倍率 0.05～4 倍。
- 预览容量上限为 10 万个粒子，单步出生预算 8192。更大的合法资产仍可编辑和保存，但预览会明确暂停，不偷偷裁剪配置。
- 性能信息显示存活数、峰值、丢弃数、碰撞数；静音 / 独奏仅作用于预览副本。
- 预览使用真实 1000 × 680 舞台，屏幕空间语义不被重写；缩放、平移仅改变舞台的显示，不改变模拟位置。
- 手动“发射 32”是临时测试，不作为资产命令记录；向前播放可看到结果，但重播、回退或重建会清除这类临时状态。
- 地面和移动路径是预览辅助场景，不会导出游戏逻辑。任意碰撞几何、项目资源数据库、跨文档编辑、Shader 编辑和崩溃恢复暂未实现。

## 测试与结构

```bat
tools\particleedit\test.bat
tools\particleedit\release\particleedit.exe --preset 5 --curves --frames 180 --capture D:\temp\editor.png
```

`test_document.c` 覆盖字段读写、JSON / XSON 往返、非法值、中文路径、失败加载不破坏文档、保存冲突、脏状态、历史截断、重排 / 删除引用修正、循环引用拒绝、曲线 / 渐变，以及全部七个模板。

`--exercise` 通过 XUI 的实际输入和控件编辑路径检查按钮、数值提交、枚举值、编辑中切换发射器、快捷键焦点隔离、曲线拖拽、时间轴区间 / Burst 拖拽与双击、播放头、Dock 浮动与恢复、固定种子回放和重复重建。不是只测试数据模型。原生文件选择框、操作系统保存确认框和交互式布局恢复还应按上面的操作流程人工验收。

| 文件 | 职责 |
| --- | --- |
| `src/pe_document.*` | 纯 C 模型、事务历史、运行时格式、原子文件操作 |
| `src/pe_fields.*` | 字段元数据、单位换算、严格值解析；界面和测试共用 |
| `src/pe_preview.*` | 运行时世界、资源生命周期、增量 seek、离屏预览 |
| `src/pe_ui.c` | XUI Dock / PropertyGrid / TimeLineView / ColorPicker 等控件装配 |
| `src/pe_graph.c` | 曲线 / 渐变图形编辑和时间轴领域交互 |
| `src/main.c` | 应用生命周期、命令、文件对话框、关闭保护、布局持久化 |
| `src/pe_exercise.c` | 原生 XUI 交互回归 |

## 参考设计

- [Defold ParticleFX](https://defold.com/manuals/particlefx/)：借鉴发射器大纲、即时预览与曲线联动的工作流程。
- [Godot 2D ParticleProcessMaterial](https://docs.godotengine.org/en/stable/tutorials/2d/particle_process_material_2d.html)：借鉴出生随机范围与归一化生命周期曲线的分组表达。
- [Unity 曲线编辑](https://docs.unity3d.com/cn/current/Manual/EditingCurves.html)：借鉴直接操作关键点和切线的交互方式。
- 本地参考了 `tools/mapedit`、`tools/UIDesign` 和 `D:\GIT\auto_test_ide` 的原生工作区、输入、布局和文件安全模式。

这些参考用于操作设计；编辑器只暴露 XGE 已有的运行时能力，没有照搬其他引擎的粒子格式、模块枚举或模拟代码。
