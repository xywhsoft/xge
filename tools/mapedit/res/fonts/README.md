# MapEdit UI font

`Consolas-with-Yahei_Nerd_Font.ttf` is copied unchanged from the local IDE
project `D:\GIT\auto_test_ide\font` at the project owner's request.
SHA-256: `35A7074585FE4AF3763DB2AAA7635AABFFB8995B6F52E61CD46C0A53E560B16B`.

MapEdit uses 18 logical pixels, matching the IDE, through XUI's TTF font loader.
The original 12px XRF files remain for historical compatibility but are not the
default or deployed UI font. Microsoft YaHei is the runtime fallback.

No redistribution license accompanied the IDE copy. Confirm font licensing
before distributing this bundled font outside the existing projects.
