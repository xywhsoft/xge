# 3D 综合 C API 范例

```bat
examples\xge_3d_integration\build.bat full-dev --run --frames 360 --capture artifacts/xge-3d/integration.png
```

构建脚本生成确定性模型测试资源；第一次缺少动作文件时运行 C 离线转换/重定向验证入口，获取已固定版本及哈希的 CC0 KayKit 素材。原始资源与许可证见 [动作资源说明](../../test/assets/3d_motion/README.md)。`3d` 配置也可构建运行，界面和二维合成随宏裁掉；full-dev 使用 Windows Segoe UI 字体。

运行库只调用公开 C API。范例加载两种模型与一个贴图模型、十二份独立外部动作，用每帧 512 B/4 操作/1 ms 软时间额度提交模型资源。工作线程不提交 GPU；加载完成后实例化，加载中可继续渲染地形和 UI。资源生命周期在创建线程管理，先释放 Loader、Animator、Scene 和 GPU 对象，再销毁上下文。

场景包含固定分块三层 LOD 高度场、80 个共享网格实例、天空、太阳两级阴影和一个聚光投影。每 60 帧切换一种动作，360 帧覆盖 idle/walk/run/jump/slash/gather。双精度全局位置约为 1e9；第 60 帧改变相对原点。第 30/90 帧分别移动/删除一个对象，应用重新读取真实静态网格和世界变换，导出三角形。

应用以斜率过滤导出的三角形，提供外部导航可消费的表面数据；向下射线使用这些复制的三角形查地面，再将应用位移与根运动写回模型位置。这是小型几何/变换接入验证，没有引入物理或导航库，不提供完整角色碰撞、寻路、台阶或斜坡解算。动态蒙皮网格被明确跳过，应用可为角色提供自己的简化碰撞形状。区域策略、生成、建造、存档和联网均不属于此范例的引擎实现。

finite `--frames N` 在十五项资源完成后开始计数；360 帧末尾检查六种动作、720 次应用地面查询、移动/删除/重定位和实际实例化/阴影提交。省略 --frames 时交互运行，XUI 按钮切换动作，Escape 退出。`--capture` 包含 full-dev 的真实 XUI 按钮，与 3D 使用相同场景；按场景尺度配置阴影偏移，降低地形自阴影纹理。
