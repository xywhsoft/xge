# 隐藏定义语法：统一 CST 的解析器前置工作

日期：2026-10-05。所属 K2/K4/E1。当前是隔离原型，尚未合入；完整 CST 与原整体目标未完成。

## 已实现与实际验证

在冻结的 209 项 Document 基线上，MD4C 私有适配器增加可选的隐藏定义语法作用域。未使用及未被选择的重复脚注正文复用现有去缩进、块、行内、表格和容器语法，并继续报告原始来源范围。正文里的脚注引用不赋予可见编号，也不增加可见引用次数；没有新增可写 Document、语义节点、NodeId 或撤销历史。

可见的块、行内和文本回调保持隔离。单独的隐藏文本观察器接收普通文本、实体、NUL 及合成文本；不能把仅报告归一化特殊文本的来源 hook 当作全部普通文本事件。合成/归一化文本的原范围继续使用解析器确认的现有来源回调，不能从输出文本猜测。两个可选回调的禁用组合、嵌套 TLS 恢复、拒绝开始、正文失败及作用域中止均有验证。

十二个独立样本和一个含 NUL 的二进制样本覆盖未使用/重复定义、传递引用、引用/列表/代码/表格、行结束、实体、空正文及缺失定义。启用前后的全部可见回调字节、脚注编号/引用次数一致；五种回调错误、取消和 92 个解析分配失败点保持 Document 身份/版本及 live 分配数不变，零泄漏。

普通与碰撞 ASan/UBSan、解析器分析、无 hook 编译，以及隐藏解析器、已合入围栏边界和来源索引工作预算三个源码驱动，共十二条全新命令实际退出 0。四个产品文件仅在隔离目录修改；209 项根目录验证输入保持不变。

证据：[隔离原型验收](D:/GIT/xge/build/source-hidden-cst-209-20261005/prototype-accepted-v6.json)。

## 下一步落地约束

1. 把语法记录接入同一 `doc_state` 的不可变存储，按定义保存块、行内、字段、文本及容器来源。相对定义起点记录范围，避免无关前文插入导致整个尾部语法数组改写；原字节继续只由 SourceStore 持有。
2. 为引用定义及语法记录保持一致的序号和父子归属，覆盖未使用、重复以及可见正文。隐藏记录无需语义 NodeId。SourceIndex 必须消费这些记录，逐步替换目前脚注正文的整体不透明角色。
3. 接入 state clone/release、当前/历史/其他内存诊断、快照、事务失败回滚、Prepare/Continue/取消及原生 Markdown 重载。
4. 接入增量和定义集合对齐。复用须证明原始范围、语法与前缀不变；仅去缩进正文值相等不能证明原始 CST 可复用，改变 Tab/容器前缀时必须更新来源和逻辑列。
5. 增加独立原字节黄金、完整重解析差分、定义数量和激活变化、全部故障点、读查询及编辑消费验证，再完成实际 DLL、平台与整批验收。

解析器原型通过不代表以上存储、索引、编辑或完整 CST 已完成；HTML 内部及其他语法来源仍按原设计继续。
