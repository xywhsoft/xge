# 脚注内部取消引用与正文块归属

日期：2026-10-04。范围：原设计 K2/E1；统一 Document 整体重构仍进行中。

## 问题与正式实现

提醒块批次结束后，正式 DLL 的脚注内部取消引用仍会把未选正文的实体、代码围栏、附加 info 和脚注首行规范化。十二个独立黄金文件均失败，包含普通引用、提醒块、列表、Tab、重复和未使用定义、表格、HTML 与 EOF。

正式来源补丁现在根据最近的脚注祖先及解析器给出的定义范围定位唯一有序定义。仅允许这个定义的正文值改变；原始标签、定义数量/种类/顺序以及其他全部定义值保持，未使用和重复定义也参与检查。前缀复制证明仍限制实际改动，完整解析必须与命令所要求的整篇语义相等，失败候选不发布。

提醒头部与脚注首行同处一行时，解析器确认的 `[^label]:` 前缀保留到第一条正文行。父引用和列表仍按原逻辑列处理；正文实体、围栏、空白和未操作的来源区间保持原字节。没有新增公共 API、旧接口包装或第二套文档历史。

同时修复 MD4C 收集脚注正文的错误：匹配外层容器之后，四列缩进的非空延续行先作为脚注输入保留，再独立解析正文。此前缩进 HTML 可以提前中断外层定义段落、变成根层 HTML，导致取消引用的完整语义检查失败。SOURCE、完整解析和原生文件重载使用同一路径；未启用脚注的解析不进入该分支。

## 保留的范围

本批处理整块取消引用及其最近的已解析脚注祖先，不代表所有脚注结构命令、部分选区操作或完整 CST/token/trivia 已完成。编辑定义正文后的缓存值会变化；本批没有证明超大脚注正文缓存的历史占用和 P95 耗时门槛。原 13 个工作包与全部设计要求继续追踪。

通用 WebView 仍仅 Windows 基础承载，其他四后端与公开通信延期；Document 内部公式、Mermaid、HTML 渲染及独立 HTML 交互保留。Linux UI 代理测试不替代真实平台、IME、读屏和物理 DPI 验收。

下一处实际失败是取消列表的来源保护：8 个独立黄金用例全部失败，7 个成功命令改写正文或未选兄弟项，包含隐藏多行定义的场景返回 -107；原始失败记录随本批保存。
