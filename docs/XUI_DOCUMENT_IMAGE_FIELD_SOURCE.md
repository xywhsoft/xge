# 图片目标字段编辑与 alt 原字节保留

日期：2026-10-05。所属 K2/E1。以嵌套图片 v4 的 190 项最终输入为基线，隔离候选 v11 的专项验证已通过；192 项最终输入、10 项拟合入已冻结，该中间候选未单独合入；2026-10-05已与字段CST候选合并，正式合入194项输入，整体重构目标继续active。

## 已确认的问题

修改资源或标题但不修改 alt 时，旧图片命令仍重新生成整个图片 token。格式、实体、转义、HTML、嵌套图片以及 alt 内的原始换行因此失去原来的拼写。隔离前一版的精确驱动已编译成功并在首个场景退出 1，直接报出 alt 保留区域被重写；这不是输出 HTML 的格式差异。

新增多行场景还确认两个缺口：语义 alt 中的硬、软换行保留为换行字符，而图片命令拒绝该字符，导致合法图片不能修改目标；合法空目标 `![foo]()` 也不能只修改标题。图像 alt 应为纯文本，换行投影为空格，原字节留在来源层；保留的独立 md4c HTML 渲染器亦遵循该规则。

## 实现

- alt 的不可变文字序列、属性和包围链接均未改变时，使用解析器确认的外层图片范围，只修改闭合 `]` 后的目标/标题后缀。原始 alt 不经序列化，也不复制进 SourceStore。
- 内嵌格式、实体、转义、HTML、嵌套图片、容器前缀和行结束保留原字节。引用图片转为明确的行内目标时保留原始 alt 与隐藏定义。
- 图片 alt 的硬、软换行投影为空格；同一个 break-source 回调仍记录原始标记与 LF/CRLF/CR 范围及折叠位置。其他文字对象继续保留原换行规则。
- Markdown 图片命令允许非 NULL 的空 URI；Rich 配置仍要求非空资源，NULL URI 仍拒绝。公共说明同步更新，函数、结构布局、ABI 和原生格式版本未增加。
- 提交前完整重解析并核对期望语义；事务、快照、位置和历史仍由同一个 Document 内核管理。

## 剩余边界

目标/标题后缀是本次明确报告的修改范围，URI 与标题各自的分隔符及空白尚未作为独立 CST 字段保留。alt 被实际修改、包围链接被修改或联合结构操作仍使用各自原有路径。本批不等于完整 CST、所有图片内部高级对象、完整 HTML 一致性或全部编辑器能力完成。
