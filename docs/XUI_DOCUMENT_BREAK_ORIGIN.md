日期：2026-10-04。所属 K2。本批正式源码、实际 DLL、Windows/Linux 和浏览器验收通过，整体重构目标 active，未完成。

## 正确性问题

任务复选框后的首个换行可能先于本段任何文字回调。旧采集器用之前的文字游标扫描来源，取到了前一个段落的换行，导致 GFM/扩展模式的全文加载与 SOURCE 编辑返回 -105。旧 DLL 和当前依赖批次 DLL 均已复现；CommonMark 同一输入成功。旧实际 DLL 还在独立黄金用例中失败：格式标记后的普通换行来源错误地包含了闭合分隔符。

调试已确认错误由 `doc_md_break_source` 的来源校验触发；不是任务标记识别失败。解析器已提供真实 trailing、hard marker 和 LF/CRLF/CR 范围，采集器不应从文字游标猜测普通 SoftBreak/HardBreak 的坐标。

## 候选实现

普通换行文字回调只建立语义 break 节点；其来源由随后解析器确认的 break hook 一次性赋值。来源起点取 trailing 或更早的硬换行标记起点，终点取完整行结束；同步更新父段落范围及游标。空任务首行和格式闭合标记后的换行共用该逻辑，不增加按文本拼写区分的特例。仍校验节点类型、软硬类型、空白、硬标记和原始换行。

图片 alt 等拥有文字对象的换行仍保留现有投影路径；代码块合成换行继续使用既有代码内容位置。这些路径及完整 CST 不因本批普通 break 修复而宣称完成。
