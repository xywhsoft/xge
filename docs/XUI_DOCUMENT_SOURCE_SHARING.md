# Document 来源补丁与定义值的持久共享

更新：2026-10-04。对应整体设计 §5 的共享存储及 §6.2 的最小安全来源补丁，属于 K2/K4/K3 的后续改进。整体目标仍在进行。

## 已确认的问题

上一批封存的实际 DLL `build/tab-prefix-20261004/native-final/xge.dll` 能保留引用包裹的最终源码拼写，但公开 ChangeSet 仍把未改正文计入整容器替换。先失败程序实际退出 1：`offset=21 old=60 new=73`。旧 DLL 在 128 KiB 正文的根层引用编辑中保留 266,036 字节历史独占分配，新版对应值为 3,803 字节；记录见本批 `sharing-before-dll-scale-v2.log`。

完整重解析还会建立新的全部定义值。链接与脚注值均为不可变派生元数据，未变化的值应当在同一 Document 的当前内容、快照和历史之间共享，不能仅因为来源坐标变化而保留另一份正文。

## 实现

来源写入器增加私有复制区间记录。根层、已有引用块、列表项的受检引用前缀路径记录原来源坐标、输出坐标与字节数；相邻连续复制合并。生成的前缀和边界换行不作为来源复制，Tab 内容边界只替换那个 Tab 字节。

执行前先验证全部复制区间有序、范围合法，并分段核对当前来源字节。随后从后到前修改复制区间之间的空隙，让 SourceStore 的未改 payload 继续共享，最后只解析一次候选。完整语义树、全部有序定义值和原子发布仍是提交门槛。普通序列化路径继续报告其实际容器改写，不以字符 diff 推断来源。

完整解析新增定义值共享步骤：数量相同时逐 ordinal 比较类型和精确缓存 payload，只替换变化项；全部相等时直接复用旧序列根，不分配替代序列。数量变化时复用可证明相等的有序前缀/后缀，拼接解析器的变化中段。重复、未使用定义和脚注正文也参与比较；来源位置不参与值相等判断。重排后的不同 ordinal 不声称自动全局去重。

该步骤位于完整解析之后、节点身份协调之前，覆盖只含隐藏定义而无可见孩子的根节点。SourceLoad、Prepare、continued Prepare 与语义候选使用同一个 Document 内核；既有增量字段替换仍只更新一个不可变值。

## 验证范围

维护的 `xui_document_source_sharing_test.c` 覆盖：

- 408 个 BOM/换行、Text/GAP、正反选区黄金来源；公开小补丁及全部 UTF-8 边界的双 affinity 映射；实际源 payload 共享和定义序列根共享；完整重载与 Undo/Redo。
- 根层、已有引用和列表项中 4 KiB、128 KiB、1 MiB 未使用脚注正文；历史独占分配不随正文规模增加。
- 80 个连续脚注正文物理行，复制区间向量扩容、稀疏来源树、精确映射和缓存值；扩容与发布的 1,167 个真实分配失败点和 1,163 个分配触发取消点。
- 36 个完整源码替换、Prepare、continued Prepare 场景，含混合定义类型、重复、插入、删除、重排、修改正文和未使用定义；仅隐藏定义的根节点；释放 Document 后快照仍可读。
- 定义缓存的 518 个分配失败点和 282 个分配触发取消点，来源、树、语法、revision、历史和存活分配保持原子。

Windows 完整发布套件实际退出 0，新增共享专项分别在 Core 和实际 DLL 执行通过，既有 136 个 Editor 引用场景继续通过。Linux Core/Renderer/View ASan/UBSan、三个修改模块 GCC analyzer、可选 Web 测试及生产构建和 5 个串行浏览器程序均实际退出 0。生产 284 项 Document API、基础/provider 导出及 14 个私有浏览器符号边界通过，三张新实际截图已查看。冻结的 84 项源码、头文件与测试输入未变。652 项 CommonMark 证明解析/来源/往返及差分，不证明 HTML conformance；Linux UI 使用无窗口代理，不代替真实后端、IME/读屏及物理 DPI。最终命令、源码、DLL 指纹和全部工作包状态见同前缀 checks-final.json、sources-final.json、hashes-final.json 和 scope-final.json。

证据前缀：`artifacts/xui-document-rebuild/validation-2026-10-04-source-sharing-`。前批封存证据保持原样；`sharing-before-dll-scale.log` 是开发工具标签误用，其编译命令使用当前 Core，不能当作旧 DLL 证据，实际旧 DLL 规模记录为 `sharing-before-dll-scale-v2.log`。

## 边界与后续

本批建立可复用的来源复制证明和持久共享执行机制，先接入三类已经证明的引用前缀写入器。它尚不覆盖来源重排、所有块内 token/trivia、其余复杂结构命令或任意完整 CST，也不把全文解析变成增量解析。大正文的临时解析/验证缓冲仍存在；历史内存专项不能代替固定机器 P95 响应门槛。

原 13 个工作包继续按完整设计追踪。真实平台、IME/读屏、DPI、性能、迁移和完整编辑余项不因本批通过而减少验收范围。通用 WebView 仍仅 Windows 基础网页承载；其他四平台后端和公共消息桥暂缓，Document 内部公式/Mermaid/HTML 通道保留。
