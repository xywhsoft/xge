## 提交规则

- 一个问题或独立控件族完成复核、回归后，使用中文 commit 单独提交。
- 并行工作在独立 worktree 进行；主线集成前复核源代码并运行相关联合回归。
- 不修改或提交其他任务的粒子系统、地图编辑器、UIDesign 等未提交内容。
- 下表中的“已修复”限定为原审计列明的缺陷和已经覆盖的场景，不代表不存在其他同类问题。

## 未宣称完成的边界

- P3-2 的全库像素类型/历史浮点字段重命名尚未完成；部分度量 API 仍接受浮点。
- 原生矩阵不是全部控件的全部状态覆盖；弹层翻转、编辑器选区/IME、多语言排版还需扩大自动化矩阵。
- 虚拟 DPI 测试不等价于真实多显示器间 DPI 迁移，也不等价于所有 OS 输入后端实测。
- 原生 accessibility 平台桥接、屏幕阅读器、虚拟集合语义和 live region 仍需专项验收。
- 回调可注入面很广，继续逐控件检查 adapter/provider；不能以一组生命周期测试替代所有公开入口审计。
- 审计中的 Inspector overlay、统一虚拟集合、cell editor host 等架构建议不作为本批已完成事项。
