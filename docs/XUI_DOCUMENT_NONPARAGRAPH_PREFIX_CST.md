## 已确认的缺陷

从根段落中部删除到深层列表内的引用段落末尾时，外层列表的首块可能是标题、引用、代码块、Mermaid、分隔线、HTML 或表格。被选中的块正文需要删除；未选中的列表标记、空引用、隐藏链接定义和根尾部需要保留。

`doc_md_write_nonparagraph_item_prefix` 原先使用 `char line[256]`，截断后无法证明完整列表标记或代码围栏开头，因而拒绝合法命令。实际解析后的七类块、祖先、来源位置和隐藏定义数量均先被独立断言确认，再执行命令；没有用看起来像 Markdown 的字符串代替语法确认。

两端旧实际共享库在 224 个有效场景中各拒绝 46 个，按标题/引用/代码/Mermaid/分隔线/HTML/表格分别为 6/6/8/8/6/6/6。围栏需要三个完整开头字节，代码和 Mermaid 比其余类型更早触及截断边界。

扩展 LF/CRLF/CR、BOM、文件结尾换行和正反选区后，两端旧实际库各完整执行 5376 个有效场景，各拒绝 1104 个。另一个独立长首行矩阵包含七类块、两种列表标记、2/53 层、4094/4095/4096/8190/8191/8192 字节首行、三种换行和 BOM，共 1008 个有效场景；两端旧库各拒绝 504 个。成功编辑均无原字节差异。
