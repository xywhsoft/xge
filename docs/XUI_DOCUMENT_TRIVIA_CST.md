# Document 语法间隙与空白来源

核对日期：2026-10-06。当前为隔离候选，未合入生产源码；整体重构目标与 K2/K4 尚未完成。

## 问题与实现

独立探针在当前正常内核确认：纯空白文档没有正文语法 arena，段落末尾、标题标记周围及块间部分空白/换行没有独立 CST 记录。来源索引仍可以把残余原字节分成空白或换行，所以零未分类字节不能证明语法来源完整。

候选在现有解析器收集结束后，按已确认的直接子项范围补齐父语法范围中的空白间隙。子项依次按父项、起点、终点排序并合并覆盖；只收集未覆盖的空格、Tab 和原始行结束，文字内容、字段、标记和不透明内容的既有归属保留。CRLF 作为一个原始行结束记录，CR 与 LF 分别按原输入保留。非空白未知内容不据此猜测 Markdown 语义。

块内记录属于原块/行内语法；文档级空白以无语义节点的 trivia block 进入已有普通语法森林。隐藏定义通过相同完成器进入已有定义 arena。两者继续共用不可变 CST 布局、来源投影、语法预算、取消机制和持久共享；没有额外解析器、源码副本、可写文档、历史或兼容 API。

最终隔离输入为 `build/source-document-gaps-20261006/candidate-v5.json` 的 242 项。相对当前 239 项生产输入，七项变化为内部常量、收集器、Markdown 接入、新空白完成器、两个永久回归驱动及标准测试入口。实现位于该目录的 `snapshot-v5`；新正常 DLL 位于 `native-v1/build`。生产输入保持冻结，供上一批正式完整回归使用。
