# XGE + XUI 官方教程质量标准

本标准把官网教程视为随源码发布的产品，而不是静态说明文字。每个章节都必须能让读者从页面进入源码、构建、运行、观察效果并理解关键设计取舍。

## 章节闭环

每章均须具备以下内容：

1. **明确目标**：说明完成本章后能够做什么，并列出前置章节。
2. **权威源码**：完整示例保存在 `examples/tutorial_capture/chNN_main1.c`；网页只能展示该源码的同步副本或可追溯摘录，不能维护第二份手写实现。
3. **可重复构建**：使用当前仓库的 MinGW-w64 构建链，并拥有可定位到章节的构建命令。
4. **可观察运行**：窗口型示例支持 `--frames N`；交互型示例还要定义自动输入或状态断言。平台特性不可用时，示例必须显示能力状态和替代路径，而不是声称成功。
5. **真实截图**：`wwwroot/tutorial/img/chNN_1.png` 由对应示例生成，文件名、尺寸和截图说明均须与章节对应。截图不能是设计占位图。
6. **教学注释**：源码注释解释资源生命周期、坐标/单位、事件或渲染时机等关键点；网页补充常见陷阱、预期输出和练习。
7. **验证记录**：构建、运行、截图和像素/行为断言必须可在自动化中重新执行；失败不得作为“已验证”发布。

## 发布门禁

`tools/audit_tutorial.ps1` 是最低静态门禁。它默认覆盖当前发布的 211 章，并要求每个已发布章节都有：

- 网页、同名权威源码和同名 PNG；
- 完整代码小节与截图说明；
- 代码块、构建说明、运行说明以及教程源码中的注释；
- 所有网页本地资源引用有效。

静态通过不代表运行正确。后续运行门禁还要验证：构建退出码、有限帧退出码、截图尺寸/像素断言，以及交互案例的事件断言。

## 推荐学习路线

1. **起步与工程化**：工具链、首窗口、帧循环、日志、资源和调试。
2. **2D 渲染基础**：颜色、坐标、相机、图元、纹理、批处理与离屏目标。
3. **矢量与 SVG**：路径、填充/描边、渐变、裁剪/遮罩、场景图和 SVG。
4. **文本与国际化**：字体、fallback、排版、UTF-8、Emoji、文本编辑、IME 与剪贴板。
5. **XUI 基础**：Proxy、Context、控件树、布局、样式、事件、缓存与资源。
6. **XUI 控件与应用模式**：输入、容器、数据、弹出层、专业控件、可访问的交互模式。
7. **综合项目与交付**：XGE/XUI 协作、性能、跨平台适配、测试、打包与发布。

现有编号保持稳定；缺失主题优先以新增章节或明确扩展章节的形式加入，不用不透明地改写旧章节的学习目标。
