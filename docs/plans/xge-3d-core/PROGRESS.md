# 通用 3D 三项完善（2026-10-25）

范围：基础碰撞查询、显式资源缓存与生命周期、场景节点 C API。复用已有场景 BVH、XRT 容器、异步加载、资源引用与分步装配；新增功能使用独立数字宏裁剪。不加入刚体求解、角色策略、游戏存档或编辑器。

- [x] 碰撞：独立于可见网格的球/盒/胶囊/静态网格，层过滤与排除自身，重叠、射线及三种凸形扫掠，静态网格三角形 BVH。
- [x] 缓存：显式所有者、规范 URI、模型/纹理共享、合并并发请求、独立取消、LRU 清理与内存统计。
- [x] 节点：父子/局部变换读取、名称与查找、借用用户数据、事务式子树克隆、轻量场景描述装配。
- [x] 公开 API 范例、CPU/GPU/裁剪/兼容性回归与体积记录。

实现顺序：节点接口 → 碰撞 → 缓存 → 综合范例和验收。验收覆盖旧句柄、失败回滚、仿射变换、模型/蒙皮引用、查询退化情况、同资源请求取消及上下文线程约束。结果写入 `artifacts/xge-core-next/`，仅通过实际验证的项目才标记完成。

## 验收结果

- `3d`、`full-dev` 各通过新增 3 组 CPU、1 组 GPU 和已有 24 组回归，共 56 组；新增 CPU 边界用例扩充后在两种配置再次通过。
- SCENE/COLLISION/CACHE/ASYNC/MODEL 分别关闭及 BARE 六种配置，源码选择、声明/导出一致性、适用运行测试与热构建复用均通过。
- 200 组随机球扫掠对照解析解，全部 9 种凸形组合；静态网格 BVH、更新、仿射变换、层过滤和重定位通过。
- 异步同键合并、独立取消、失败重试、发布时内存不足回滚、上传中取消及共享纹理通过；缓存释放后模型仍可渲染，配额最终无遗留分配。
- 蒙皮克隆姿态独立，删除源实例后继续动画/渲染；缺失外部关节、克隆/描述表中途失败均回滚。
- 综合范例 360 帧自动路径完成碰墙及绕行，1 个加载资产/3 次缓存命中，51 次阻挡，最终 x=3.65；截图为 `artifacts/xge-core-next/demo.png`。
- 本轮纯 3D 基线 925,675 B，当前 966,123 B，增量 40,448 B；916 个旧导出全部保留，新增 32 个，27 个代表性旧结构 sizeof 一致。

运行命令与边界见 [使用指南](../../guide/3D_CORE.md)，范例见 [xge_3d_core](../../../examples/xge/xge_3d_core/README.md)，证据清单为 `artifacts/xge-core-next/verification.json`。验收平台为 Windows 原生 GL；代表性 sizeof 检查不等同完整 ABI 证明。本轮未验收 GLES/WebGL2、其他系统或全部 XUI/default 回归。

SceneLoad 使用 C 描述表并接入现有 glTF/缓存，文件格式由应用决定。静态网格碰撞是表面查询，缓存预算为可观测的软目标；不扩展到物理求解器、游戏存档或游戏玩法抽象。
