# 动画播放完善

复用现有八层覆盖/加法、遮罩、事件和根运动。新增自动权重淡化、剪辑过渡、完成状态、整体/分层暂停；不增加动画图或游戏状态机，保留 C、xrt 和 ANIMATION 裁剪。

- [x] 播放/停止与自动淡入淡出，支持连续打断过渡。
- [x] 整体和分层暂停、播放信息与非循环完成状态。
- [x] 与遮罩、加法层、事件、根运动、失败回滚共同工作。
- [x] 公开 C API 范例，CPU/GPU/裁剪/兼容与体积验收，文档。

构建隔离在 `build/animation-playback/`，证据在 `artifacts/xge-animation-playback/`，基线为本轮开始前的 DLL/头文件。仅实际验证后标记完成。

2026-10-26 验收：

- `3d` 和 `full-dev` 各 31 组 CPU/GPU 回归，共 62 组通过；包含旧模型/动画/渲染/阴影/碰撞/缓存/分步上传和 2D/XUI 混合绘制路径。
- 新 CPU 用例验证移动的旧剪辑、30 次连续打断、不同通道和遮罩、八层中的加法平移/旋转/缩放、两种暂停、零时长动作、非循环完成和末帧保持、淡出停止、事件及根运动。队列溢出保留状态，65 种分配限额覆盖绑定/快照失败，最终引用和预算无遗留；预热后的 120 步 Update 没有分配拒绝。
- 9 组真实蒙皮 GPU 图像与独立手工设置的参考姿态逐字节相同，覆盖过渡、打断、暂停、恢复和加法叠加；释放调用者持有的剪辑引用后继续运行。
- ANIMATION、MODEL、ASYNC 分别关闭及 BARE 四种配置，通过实际源码选择、消费者头文件/导出一致性、适用 CPU/GPU 测试和热构建复用。core（3D 关闭）构建成功，源码/声明/导出均没有 3D。
- 纯 3D DLL `972,779 → 979,435 B`，增加 `6,656 B`；范例裁剪 SDK 为 `911,851 B`。951 个旧导出全部保留，新增 5 个；59 个旧公开 3D 结构文本、sizeof 和 alignment 相同。旧头文件/配置编译的动画消费者在新 DLL 上通过，检查不等同完整 ABI 证明。
- 自有模型公开 C API 范例运行 420 帧，完成 1 次一次性动作、消费 5 个事件，涵盖两种暂停和叠加停止；已保存并检查截图。

使用说明：[动画播放指南](../../guide/3D_PLAYBACK.md)。范例：[xge_3d_playback](../../../examples/xge/xge_3d_playback/README.md)。证据清单：`artifacts/xge-animation-playback/verification.json`，包含测试结果、配置、截图、兼容检查和对应文件哈希。

范围保持 C/xrt、现有 ANIMATION 宏和有限存储，无新增依赖、动画图或游戏状态机。连续打断保证姿态连续；旧混合源冻结后不保证速度连续。大 dt 下的非线性/STEP/末尾截断根运动采用平均权重近似，应用使用小固定步长。验收平台为 Windows 原生 GL，其他系统、GLES/WebGL2 与完整 XUI/default 套件未实机验收；工作区其他 XUI 修改保持原样。
