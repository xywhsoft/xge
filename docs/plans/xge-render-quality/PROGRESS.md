# 基础渲染完整性

范围：线性颜色/透明合成、可裁剪基础抗锯齿、节点阴影投射/接收。沿用 C、xrt、现有材质/目标/渲染接口，不加入游戏逻辑或大型渲染框架。

- [x] 线性空间合成，统一输出 sRGB；透明离屏结果保持显示空间预乘 Alpha，兼容既有 2D 合成。
- [x] 可选 FXAA，独立数字宏裁剪；缓存中间目标，尺寸改变时事务式重建。
- [x] 节点投射/接收开关，覆盖实例化、蒙皮、克隆、阴影层组合。
- [x] CPU/GPU、GL 状态及混合绘制回归、裁剪、范例、体积与文档。

使用本轮开始前的 `artifacts/xge-render-quality/baseline-*` 比较增量，构建输出隔离在 `build/render-quality/`。通过实际测试后记录结果。

2026-10-26 验收：

- 3d/full-dev 各 29 组回归，共 58 组通过；包括真实 2D/XUI 混合绘制、旧空间/缓存/动画/上传路径及新增 GPU 检查。
- 透明红覆盖蓝约为 `(188,0,188)`；透明输出预乘一致，曝光与发光在合成前不被 8 位颜色截断。五种深度格式、sRGB 外部目标、无清屏保持、偏移/非法视口、尺寸变化及上传 PBO 状态通过。增强发光用例在两种主配置与四种裁剪配置再次通过。
- FXAA 固定三角形场景改变 582 个边缘像素，产生 581 个过渡像素；关闭后逐字节恢复原图，透明背景无超出 Alpha 的亮边。
- 投射/接收与层、共享实例、蒙皮和克隆组合通过；不同接收标志的实例化结果与逐物体提交像素一致。
- FXAA、SHADOW、LIGHTING、BARE 四种配置的实际源码/声明/导出/着色器裁剪、运行测试和热缓存通过；core（3D 关闭）构建通过，非法 FXAA 宏组合被拒绝。
- 纯 3D DLL 966,123 → 972,779 B，增加 6,656 B；FXAA-off 为 971,755 B，范例 SDK 为 783,636 B。948 个旧导出保留，新增 3 个；59 个旧公开 3D 结构 sizeof 相同，未声称完整 ABI 证明。
- 无资源下载的公开 API 范例，AA 关闭/开启、投射关闭和接收关闭四种状态各运行 30 帧并保存截图。

使用说明：[渲染完整性](../../guide/3D_RENDER_QUALITY.md)。范例：[xge_3d_render_quality](../../../examples/xge/xge_3d_render_quality/README.md)。证据清单：`artifacts/xge-render-quality/verification.json`，包含测试日志、配置、截图和对应源码/二进制哈希。

验收为 Windows 原生 GL；其他系统、GLES/WebGL2 和完整 default/XUI 套件未实机验收。保留当前对象级透明排序边界；没有增加物理、玩法、HDR 素材管线或大型后处理框架。工作区其他 XUI 修改保持不变。
