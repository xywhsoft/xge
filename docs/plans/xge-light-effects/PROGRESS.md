# 轻量画质增强

首批范围：色调映射、基础调色、低分辨率 Bloom、解析高度雾。复用前向渲染和 RGBA16F 合成器，保持 C/xrt、现有公开结构布局与预乘透明约定。默认关闭，独立数字宏裁剪，不添加光影包加载器或游戏规则。

- [x] 色调映射/调色合入现有输出阶段，运行时关闭保持原图。
- [x] Bloom 按需申请小尺寸纹理链；关闭跳过所有额外 Pass 并回收纹理。
- [x] 高度雾支持透视/正交、场景原点重定位及旧距离雾组合。
- [x] 公开 C API 范例、数值/GPU/状态与裁剪回归、体积及文档验收。

隔离构建在 `build/light-effects/`，证据在 `artifacts/xge-light-effects/`；基线为本轮变更前用同一工作区和工具链构建的 DLL。仅按实际结果记录完成状态。

2026-10-28 验收：

- `3d` 和 `full-dev` 各 33 组 CPU/GPU 回归，共 66 组通过，包括原有模型、材质、蒙皮、动画、阴影、碰撞、缓存和上传路径，以及 2D/XUI 混合绘制。新的效果开启后，后续 2D 绘制颜色保持原值。
- Reinhard/拟合 ACES 各验证 8 个输入；增益、饱和度、对比度和透明预乘验证通过。旧头文件编译的渲染测试能在新 DLL 运行，默认 AA 关闭/开启两张图与基线 PNG 逐字节相同。
- Bloom 验证常量能量、柔和阈值极值、1620 个透明轮廓外光晕像素、关闭逐字节恢复、奇数和 1×1 尺寸、层数缩减、预热后无 C 分配及首次 Shader 内存失败重试。关闭时额外 Pass 和专用纹理字节均为 0；128×128 四层为 7 Pass / 43,520 B。
- 高度雾与解析值比较通过，覆盖水平/倾斜视线、透视/正交、均匀密度、最大不透明度、旧距离雾与曝光组合。全局坐标平移至十亿米量级及继续重定位原点后，画面保持一致；关闭恢复原图。
- TONEMAP、COLOR_GRADING、BLOOM、HEIGHT_FOG、FOG 分别关闭及 BARE 六种配置，实际源码/声明/导出/GLSL 裁剪、适用运行测试和热缓存通过。四项新增效果同时关闭另通过 6 组 GPU 回归；core（3D 关闭）构建通过。8 种非法宏配置被拒绝。
- 纯 3D DLL `979,435 → 987,115 B`，增加 `7,680 B`（7.5 KiB）；四项同时编译关闭为 `979,435 B`，与本轮基线大小相同。956 个旧导出全部保留，新增 7 个；60 个旧公开 3D 结构文本、sizeof、alignment 相同，检查不等同完整 ABI 证明。
- 无外部资源的公开 C API 范例已运行全开/全关各 60 帧并检查截图。960×640 四层 Bloom 为 7 个额外 Pass / 1,632,000 B，关闭为 0 / 0；裁剪范例 SDK 为 `790,804 B`。GPU 时间仅记录示例采样，不作为固定性能承诺。

使用说明：[轻量画质指南](../../guide/3D_LIGHT_EFFECTS.md)。范例：[xge_3d_light_effects](../../../examples/xge/xge_3d_light_effects/README.md)。证据清单：`artifacts/xge-light-effects/verification.json`，包含配置、结果、兼容检查、截图和对应文件哈希。

范围边界：启用 Color/Bloom 要求本次 Render 清颜色，并在后面绘制 UI，防止重复处理已映射画面。新增效果默认全关，保留原前向管线，无光影包依赖、动画图或游戏规则。Bloom 是空间滤波，高度雾是全局 Y 密度积分，不含体积散射、实时 GI、SSR 或时序历史。验收平台为 Windows 原生 GL；其他系统、GLES/WebGL2 和无关完整 XUI/default 套件未实机验收。工作区其他 XUI/xrt 修改未更改。
