- [x] 接触/穿透查询和有限迭代的恢复、扫掠、滑动。

- [x] 批量 Billboard、序列帧、透明/加法混合及有限容量 CPU 粒子。

隔离构建：`build/game-foundation/`。证据：`artifacts/xge-game-foundation/`。本轮基线为实施前工作区的 3D DLL，987,115 B，包含上轮尚未提交的轻量画质功能。其它工作区改动保持原样。只按实际完成的测试记录验收结果。

## 验收结果

- `3d`、`full-dev` 各 36 组 CPU/GPU 回归，共 72 组通过；保留原 33 组，新增通用基础 CPU、GPU 和着色器阴影三组。新增用例扩充后在两个配置再次通过。
- 动作映射验证相反输入、限幅/死区、重绑/禁用/Reset、按下释放边沿、非法回调值的整体回滚及容量限制；预热 Update 在 1 B 分配配额下无分配拒绝。core 的动作模块分别开启/关闭，两种独立消费者均通过，源码与导出均无 3D。
- 粒子验证容量与丢弃统计、种子重现、独立解析抛物线参考、生命周期/颜色/序列帧及非法 dt；预热 Emit/Update/导出在 1 B 配额下无分配拒绝。
- 碰撞验证全部 9 种仿射凸形接触组合，沿返回法线修正后不再重叠；80 组球对球与解析解一致。还验证初始接触时向外移动、恢复距离上限、墙面/墙角滑动、静态三角形胶囊恢复、过滤器及错误保留旧输出。
- GPU 验证材质原位更新、纹理子区域/PBO/unpack 状态恢复，目标视图的透明/色彩/方向、Resize、调用方释放目标后的寿命、禁止反馈且保留原图。调试绘制验证深度开关、盒/轴/骨骼和清空；Billboard 验证排序、Alpha/Add 数值、深度遮挡、相机朝向、批次与预热复用。
- 自定义着色器验证参数、非法 GLSL/参数失败、蒙皮、实例化和位移包围边界；顶点变形/透明裁切/蒙皮阴影与独立放置、隐藏或标准材质参考图逐字节相同。日志中的非法 GLSL 编译错误是预期负例。
- DEBUG_DRAW、MOTION、DYNAMIC、SHADER、BILLBOARD、PARTICLES 分别关闭及 BARE 共七种配置，通过声明/实际导出、源码选择、GLSL 裁剪、适用运行测试与热构建；扩充后的 CPU/GPU 新用例又在七种配置分别通过。另验证六项同时编译关闭及 core 输入开/关；15 种非法宏/依赖配置均被拒绝。
- 纯 3D DLL `987,115 → 1,034,731 B`，增加 **47,616 B（46.5 KiB）**。六项同时关闭为 `988,651 B`，比基线增加 1,536 B，为共享渲染/GJK 底座重构的残留增量，不宣称完全零增量。core 输入关闭/开启为 `690,803 / 693,875 B`。裁剪范例 SDK 为 `851,732 B`，没有新增第三方依赖。
- 基线 **963 个导出全部保留，新增 34 个**。64 个旧公开 3D 结构的正文、sizeof 和 alignment 一致；旧头文件消费者在新 DLL 运行成功，默认 AA 关闭/开启两张 PNG 与基线逐字节相同。这些检查不是完整 ABI 证明。
- 无外部素材范例运行 240 帧，记录 162 次墙面接触，最终位置 `(1.499, 0.800, 1.499)`、25 个活动粒子；截图已检查。范例只使用公开 API，重力与自动输入路径留在范例层。

完整检查：`python tests/xge/check_game_foundation.py --trimming`。结果清单为 `artifacts/xge-game-foundation/verification.json`，包含测试结果、构建配置、源码/测试/库哈希、兼容性及截图。

验收平台为 Windows 原生 GL；GLES/WebGL2、Android/iOS 及完整 XUI/default 套件未实机验收。full-dev 检查为上述 3D 回归与其中的 2D 混绘路径。保持原有前向渲染，不增加完整物理世界、角色玩法、粒子编辑器或材质图；界限与使用契约见 [使用指南](../../guide/GAME_FOUNDATION.md)。
