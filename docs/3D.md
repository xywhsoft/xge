# 3D C API

当前提供场景、节点、相机、共享 GPU 网格、glTF/GLB 模型、材质、直接 PBR 光照、太阳级联与聚光阴影、静态 IBL、拾取、天空盒、骨骼动画、视锥裁剪、GPU 实例化、静态 LOD、相对原点、可裁剪高度场、预算异步模型加载及独立深度目标。

综合运行、实测体积/性能及最终边界见 [3D 交付记录](3D_RELEASE.md)。

```bat
build_dll.bat 3d
test\build_3d_suite.bat all 3d
examples\xge_3d\build.bat 3d
build\3d\xge_3d.exe --frames 3 --capture artifacts\xge-3d\example.png
```

应用使用对应目录的 `xge_build_config.h` 和导入库，详见 [构建配置](BUILD_PROFILES.md)。`full-dev` 同时包含 2D、3D 与 XUI；精简界面与三维组合可用 `python tools/build_profile.py ui-min --define XGE_ENABLE_3D=1`。

坐标为右手系，Y 向上，相机观察负 Z，米和弧度。矩阵按列存储。`XGE3D_TRANSFORM_IDENTITY` 初始化位置、四元数和缩放；零四元数非法。相机使用 `xge3dCameraPerspective` 或 `xge3dCameraOrthographic`，再用 `xge3dCameraLookAt` 设置观察位置。

`xge3dSceneCreate` 拥有节点。节点由带代次的句柄引用，句柄携带所属场景，删除或跨场景使用会被拒绝。创建时可指定父节点，零句柄表示根。更换父节点保留局部矩阵；删除节点同时删除所有后代。`xge3dNodeSetMatrix` 保留完整仿射矩阵，包括剪切；`xge3dNodeGetWorldMatrix` 计算父子变换。隐藏父节点会隐藏后代。

`xge3dMeshCreate` 复制局部顶点及 16/32 位索引，也支持无索引三角形。节点通过 `xge3dNodeSetMesh` 持有网格引用，多个节点共享 CPU/GPU 数据。应用释放创建引用后，节点仍可使用它。网格在有上下文时创建或更新即上传，否则首次绘制上传；普通帧不重复上传。更新失败保留原网格。当前以 `xge3dNodeSetColor` 设置颜色。

GPU 对象由拥有上下文的线程创建、绘制和释放。在 `xgeRun` 的帧回调内创建 `xge3d_renderer` 和 `xge3d_target`。离屏目标包含 RGBA8 颜色和 24 位深度，创建失败清空输出，尺寸变更失败保留旧目标。目标纹理是借用值，不能修改或释放；作为二维图像绘制时按离屏纹理方向使用 `XGE_DRAW_FLIP_Y`。读回结果为自上而下 RGBA8，提供足够存储和行跨度。

`xge3dRender` 接收相机、目标和清除参数；目标为 NULL 时使用当前帧缓冲和视口，当前目标必须具备深度附件。调用先 Flush 二维队列，成功或失败均恢复它改变的 GL 状态，可在三维前后继续绘制二维和 XUI。旧二维离屏目标只有颜色/模板，因此直接向它提交三维会返回不支持；使用新的三维目标或具有深度的窗口。

释放顺序为场景（节点引用）、应用持有的网格、目标和渲染器，然后销毁窗口/上下文。CPU 场景、相机和未上传的网格可以在 `xgeInit` 前准备。已上传对象不能跨上下文复用；错误上下文会拒绝绘制和更新。并发场景修改及跨线程 GPU 释放不在当前契约内。

Windows 原生 GL 路径已验证。着色器根据现有后端选择 GL 3.3 或 GLES 3.0 头；GLES/WebGL2 尚未实机验证。

## 异步模型与 GPU 上传预算

`XGE3D_ENABLE_ASYNC` 默认跟随 MODEL，设为 0 时同时移除独立 TU、声明及导出。每个 Loader 使用一个 xrt 工作线程，复用 SlotMap、Array、Mutex、Cond 和 Atomic。Loader 由创建线程请求、查询、提交、取消和释放；GPU 提交和释放同时要求该线程拥有上下文。默认最多 64 个请求，可设置 1～1024；取消但仍在读取的请求在 CPU 清理结束前占用容量，容量不足返回 OUT_OF_MEMORY。URI 会复制，调用后可释放输入字符串。

```c
xge3d_loader *loader = NULL;
xge3d_request_t request;
int result = xge3dLoaderCreate(NULL, &loader);
if (result == XGE_OK)
    result = xge3dLoaderRequest(loader, "assets/actor.glb", &request);
/* In the context thread's frame callback: */
xge3d_upload_budget_t budget = {256 * 1024, 1000, 8};
xge3d_upload_stats_t uploads;
if (result == XGE_OK) result = xge3dLoaderPump(loader, &budget, &uploads);
xge3d_request_info_t info;
if (result == XGE_OK) result = xge3dLoaderStatus(loader, request, &info);
if (result == XGE_OK && info.state == XGE3D_REQUEST_READY) {
    xge3d_model *model = NULL;
    result = xge3dLoaderTake(loader, request, &model);
    if (result == XGE_OK) result = xge3dModelInstantiate(scene, model, parent, &root);
    xge3dModelFree(model);
    /* Take invalidates request; stop querying/pumping this handle. */
}
```

工作线程只做 CPU 读取、glTF 解析、图片解码与网格转换。状态依次为 QUEUED、LOADING、CPU_READY、UPLOADING、READY；只有 READY 能 Take，模型的全部网格和纹理上传后才发布。动作文件等没有 GPU 资源的模型可直接完成，也可在初始化窗口前 Take。FAILED 的 result 是实际错误，CANCELLED 的 result 为 ERROR。pending_cleanup 表示仍有 CPU 工作或清理；取消后变为 0 才能确定后台已结束。

一次 Pump 的字节和操作额度由所有请求共用；默认按请求顺序推进。bytes/operations 任一为 0 时暂停 GPU 工作，microseconds 为 0 时关闭时间检查。顶点/索引按字节续传，图片按整行或行内像素续传，因此大资源也能在小额度下完成。纹理像素至少需要 4 B；不足时 min_next_bytes 报告 4。upload_bytes/total_bytes 只统计实际传输的原始 RGBA8、顶点和索引；存储分配、数据传输和 mip 生成分别占一次操作，mip 无 CPU 上传字节。

时间限额在操作之间检查，属于软限制；完整 BufferData/TexImage 存储分配、单次传输、mip 或驱动调用仍可能超过期限。预算覆盖模型资源，渲染器着色器、实例矩阵、蒙皮姿态、阴影和渲染目标的首次分配及后续更新仍由原渲染路径处理。Pump 会先 Flush 二维队列，并恢复自身修改的状态，包括纹理解包参数和像素解包缓冲；GL 互操作和最终像素已验证。

取消立即禁止发布，并由所有者线程释放已提交的 GPU 半成品；不可分割的文件读取/提供者回调/解析操作在返回或下一检查点后清理。Release 还立即使句柄失效；旧工作完成不能发布到代次不同的新请求。Take 转移模型所有权并使请求失效；取消、失败或不用的请求由应用 Release。LoaderFree 取消全部、等待工作线程、清理剩余资源，需在上下文销毁前调用；被阻塞的提供者可能使 Free 等待。已 Take 的模型不受 LoaderFree 影响。

默认 IO 只接受普通路径及 file://，直接使用 xrt 文件读取，避免后台访问可变的全局资源注册表。指定 `XGE3D_LOADER_RESOURCE_PROVIDERS` 后通过现有 xgeResource 读取外部依赖；注册表在 CPU 工作结束前必须保持不变，load/free 回调及用户数据须能跨线程使用，用户数据还要存活到相关模型释放。不要从资源回调重入同一个 Loader。失败不发布半成品，Status 保留原因；Pump 的 failed 统计此轮失败数量，可以继续处理其他请求。主线程没有上下文时，含 GPU 资源的提交返回 NOT_INITIALIZED，保留 CPU_READY 供稍后续接。

```bat

python test/test_3d_async_trim.py
```

## 裁剪、实例化与应用 LOD

渲染器默认用保守世界 AABB 做主视锥和各张阴影视锥裁剪。静态网格的局部包围盒在创建/更新时缓存；蒙皮先计算每个关节的共享顶点包围盒，再按实例姿态变换并合并，不在每帧扫描全部顶点。主相机外的网格仍参与阴影候选。`disable_culling=1` 可作同场景对照，visible_meshes/culled_meshes 统计主视锥候选结果。

同一网格、材质、节点颜色和缩放朝向的静态 Opaque/Mask 对象自动合并为 GPU 实例绘制，主通道与阴影共用此规则。蒙皮和 Blend 保留独立提交。`disable_instancing=1` 可作对照。各通道缓存世界矩阵纹理，矩阵及候选集合不变时上传 0 B；移动或改变候选会更新对应通道的矩阵。draw_calls 是实际 GPU 提交数，triangles 按实例数累计并包含阴影，instanced_draw_calls/instances 单独报告批次。实例矩阵最多为每通道 `64 * GL_MAX_TEXTURE_SIZE` 个；超过明确返回不支持。资源只在出现批次时分配，由 RendererFree 释放，网格 VAO 仍独立持有。

`xge3dNodeSetLods` 为静态节点复制并保留最多三个额外网格，形成含原始网格的最多四级 LOD。距离阈值为正且严格递增，按相机到节点原点的距离选择，太阳和聚光阴影使用相同级别。引擎不生成简化资产，不在不同网格间做几何渐变。蒙皮节点暂不接受此静态 LOD 接口。

```c
xge3d_lod_t levels[] = {{medium_mesh, 20}, {low_mesh, 60}};
int result = xge3dNodeSetLods(scene, node, levels, 2);
/* Caller may now release its medium/low mesh references. */
```

包围盒合并所有级别；拾取和 `NodeGetMesh` 始终使用原始网格，便于保持选择及外部几何接入的一致性。`NodeSetLods(NULL,0)` 清除额外级别，`NodeSetMesh` 更换原始网格时也清除级别。配置失败保留旧级别。当前 CPU 遍历/空间查询为线性扫描，自动批次按材质排序；没有增加空间树或通用绘制队列框架。

## 相对原点与空间接口

应用持有全局双精度坐标，先为场景设置附近的原点，再调用 `NodeSetGlobalPosition` 放置根节点。子节点仍用普通局部变换。场景矩阵、光源、相机、射线及命中坐标均相对当前原点；`SceneSetOrigin` 用缓存的双精度根平移重新计算局部平移，整场景失败时保持旧原点及矩阵。它不会自动更新应用的相机和射线。

```c
xge3d_dvec3_t origin = {1000000000, 0, 0};
xge3dSceneSetOrigin(scene, origin);
xge3dNodeSetGlobalPosition(scene, root, (xge3d_dvec3_t){1000000000.25, 0, 0});
xge3dCameraLookAtGlobal(&camera, origin,
    (xge3d_dvec3_t){1000000000.25, 2, 5},
    (xge3d_dvec3_t){1000000000.25, 0, 0}, (xge3d_vec3_t){0,1,0});
```

`RelativePosition` 在 double 下相减后才转 float。太阳阴影的纹素对齐基准也跟随全局原点，重定位后保持投影一致。应用负责原点位置、区域加载和游戏数据；已经以远距离 float 输入的精度无法恢复，普通子层级也没有无限精度。更换父节点保留局部矩阵，成为根节点时重新确定全局平移；对根节点调用普通 SetMatrix/SetTransform 会以当前原点重建其全局平移。

`MeshGetBounds` 借助缓存给出局部 AABB；`NodeGetBounds` 给出保守世界 AABB，可合并后代且包含隐藏几何，空几何返回 NOT_FOUND。`RayAabb`、`RaySphere`、`RayTriangle` 的射线方向可非单位，输出距离为米，球或盒内起点距离为 0。`AabbIntersects`、`SphereIntersectsAabb`、`CameraIntersectsAabb` 包含接触边界。`SceneQueryAabb` 只返回可见网格节点；NULL/0 可查询总数，容量不足时保留前缀并返回 BUFFER_TOO_SMALL。模型射线先用包围盒排除对象，再测试真实变形三角形。

外部物理或导航可通过 `SceneNodeAt` 遍历借用句柄、`NodeGetMesh`/`MeshGetData` 读取原始顶点和索引，再用 `NodeGetWorldMatrix` 转换顶点到当前局部世界。蒙皮几何还需按 `NodeSkinMatrices` 与顶点权重变形，动态角色通常由应用提供简化碰撞形状。外部模拟结果通过 SetMatrix/SetTransform 写回节点；创建/删除仍用 NodeCreate/NodeDestroy。引擎只交付真实几何、变换与查询，角色解算、导航网格构建及寻路策略留在外部。

## 可裁剪高度场

`XGE3D_ENABLE_TERRAIN=0` 同时移除声明、导出和独立编译单元。`TerrainCreate` 复制 uint16 或 float 行数据，支持行跨度，按 `sample * height_scale + height_offset` 转成 float 高度；没有 8 位转换。高度数组、网格和材质引用由 Terrain 拥有。每个维度 2～65,537 个采样点，cell_size 为正的米/格；chunk_cells 是 4～256 的二次幂，边缘不足一块时保留剩余格。输入内存须覆盖所有行。建议用 TerrainDefault 初始化，再填写尺寸和数据。

```c
xge3d_terrain_desc_t d = xge3dTerrainDefault();
d.heights = height_u16; d.width = width; d.depth = depth;
d.format = XGE3D_HEIGHT_U16; d.height_scale = 0.01f;
d.cell_size = 1; d.chunk_cells = 32;
xge3d_terrain *terrain = NULL; xge3d_node_t root;
int result = xge3dTerrainCreate(&d, &terrain);
if (result == XGE_OK)
    result = xge3dTerrainInstantiate(scene, terrain, (xge3d_node_t){0}, &root);
xge3dTerrainFree(terrain);
/* Ordinary node transforms place the whole terrain; scene owns its references. */
```

1～4 级网格分别取 1、2、4、8 格步长，有限块的最后一行/列精确保留边界。每块为普通节点，中心作为 LOD 距离原点；lod_distances 沿用静态 LOD 的距离契约。UV 按整张地形的 X/Z 尺寸归一化，材质可调整纹理重复次数。未提供材质时创建白色、非金属 PBR 材质；应用也可给各块设不同材质和颜色。主渲染、视锥、太阳/聚光阴影和空间接口直接复用网格路径。

每级边缘都生成垂直裙边。skirt_depth 为 0 时，自动取整张输入的高度范围加 0.1 格深度，覆盖不同级别的边界高度差；也可由应用明确设置。裙边遮挡接缝空洞，粗细表面仍可能出现台阶，近距离强制使用粗级别或给出过小裙边深度会降低接缝质量。没有几何渐变、动态编辑、地形纹理混合、自动世界流式管理或洞穴。TerrainInfo.bounds 描述表面；节点包围盒还包含裙边。

实例持有全部级别及材质引用，可以立即释放 Terrain 创建引用。查询原始高度时则保留 Terrain。`TerrainChunkMesh` 返回借用的实际网格和块平移，可用于导出外部导航/碰撞几何。实例创建失败会删除已生成的子树；创建、释放已上传资源遵守上下文线程约定。

`TerrainSample(terrain,lod,x,z,...)` 在指定级别的实际对角三角形内插值并返回面法线，避免用双线性值替代绘制表面。`TerrainRaycast` 测试该级别的表面与裙边，输出块编号及块内三角形索引。坐标在地形局部空间，不会隐式读取某个实例变换。渲染器按距离逐块选级别，查询使用显式统一级别；碰撞通常固定 0 级。需要世界空间拾取时使用场景射线接口，它对节点变换后的原始网格求交，依然固定详细表面。XGE 不自动创建碰撞体或导航数据。

## 模型与材质

`xge3dModelLoad` 通过 `xgeResource` 加载 GLB/glTF 和相关缓冲、图片，支持相对路径、data URI、内嵌图像与资源提供者。`xge3dModelLoadMemory` 复制输入；base_uri 指定逻辑文件路径，用于定位外置资源。`xge3dModelInstantiate` 创建保留源层级和矩阵的共享实例；根节点用于放置整模型，`xge3dModelInstanceNode` 按源索引查找子节点，`xge3dModelNodeName` 返回借用名称。实例持有模型，应用可立即释放加载引用。

```c
xge3d_model *model = NULL;
xge3d_node_t root;
int result = xge3dModelLoad("assets/scene.glb", &model);
if (result == XGE_OK) result = xge3dModelInstantiate(scene, model, (xge3d_node_t){0}, &root);
xge3dModelFree(model);
if (result == XGE_OK) {
    xge3d_transform_t t = XGE3D_TRANSFORM_IDENTITY;
    t.position = (xge3d_vec3_t){2, 0, -5};
    result = xge3dNodeSetTransform(scene, root, &t);
}
```

基础材质支持 base color、metallic/roughness、normal、occlusion、emissive 五种贴图输入，UV0/UV1、纹理变换、采样器、Opaque/Mask/Blend 和双面。颜色与发光贴图为 sRGB，数据贴图为线性，Alpha 不预乘。`xge3dTextureCreate` 复制 RGBA8 图片，`xge3dMaterialDefault` 初始化正确默认值；材质持有贴图，节点持有材质，实例共享模型材质。GetDesc 和 ModelMaterial 返回借用值。发光加入最终线性照明；AO 用于间接照明，当前直接光不会被 AO 降低。无材质的程序化网格保留 NodeSetColor 平涂路径。

基础透明按对象原点距离从远到近排序，不写深度；相交透明面、单网格内部透明排序与线性空间透明合成不在当前支持范围。支持非索引/16 位/32 位三角形及 sparse 顶点；缺少法线时生成平面法线。当前支持 `KHR_materials_unlit`、`KHR_texture_transform` 和开启光照时的 `KHR_lights_punctual`。未知必需扩展返回不支持；Draco、meshopt 和 morph 尚未实现，不能将解析器能力当作运行库能力。

## 直接光照

用 `xge3dLightDefault(type)` 初始化方向光、点光或聚光灯，再通过 `xge3dNodeSetLight` 绑定节点；传 NULL 移除。位置与方向随节点父子变换，隐藏节点或父节点会隐藏光。方向表示局部光线传播方向，默认负 Z。颜色为线性 RGB；方向光强度按 lux、点光和聚光按 candela；后两者使用平方反比衰减，range 为米，0 不限制距离。聚光内外角使用弧度，满足 `0 <= inner < outer < pi/2`。

当前使用少量灯光的前向 GGX/Smith/Schlick PBR，每次最多 8 个可见非零强度灯光，超出明确返回不支持。Lit 材质没有光源时除发光外为黑色；unlit 材质保持基础颜色。材质粗糙度内部最低 0.045，避免数值奇异。法线贴图使用实际 UV 导数形成切线空间。render_desc.exposure 为线性倍率，0 使用 1；当前没有 HDR 后期和自动曝光。

## 距离雾

`XGE3D_ENABLE_FOG` 默认跟随 3D，关闭会移除雾设置类型、默认值函数、渲染描述字段和着色器实现。库与调用者必须使用同一配置。`render_desc.fog=NULL` 禁用；否则传入本次调用借用的 `xge3d_fog_settings_t`。`xge3dFogDefault()` 返回线性 RGB `(0.57, 0.73, 0.85)`、起点 60 米、终点 300 米。

雾在 `start` 到 `end` 间按相机前向深度线性混合，支持透视和正交相机、普通/蒙皮/实例网格及无光照材质。在材质光照与发光之后、曝光与 sRGB 转换之前应用，不改变透明度、深度、阴影或天空盒。颜色必须为有限非负值，距离必须满足 `0 <= start < end`；不合法参数在修改 GL 状态前拒绝。天空盒的地平线颜色可与雾色匹配，参见 [岛屿行走范例](../examples/xge_3d_walk/README.md)。

## 拾取与天空

`xge3dCameraScreenRay` 接收左上角为原点的像素坐标与视口尺寸，返回近裁剪面起点与单位方向。`xge3dSceneRaycast` 命中可见节点的实际双面三角形，包括骨骼变形，返回距离、世界位置、法线、三角形编号及所属模型实例根；未命中返回 NOT_FOUND 并清空结果。传入正的最大距离，方向会归一化。`xge3dMeshGetData` 借用网格 CPU 几何用于应用集成，更新或释放后失效。当前射线查询线性遍历三角形，空间加速随 P5 加入。

`xge3dEnvironmentCreate` 复制相同尺寸的六张方形 RGBA8 图片，顺序为 +X/-X/+Y/-Y/+Z/-Z，面方向见头文件注释。把环境传给 render_desc.environment；首次绘制上传，后续复用。天空响应相机旋转，忽略平移，并与场景共用深度边界。环境是本次调用的借用指针，必须在上下文销毁前释放。

模型放置、点击选择与天空组合范例：

```bat
examples\xge_3d_scene\build.bat 3d
build\3d\xge_3d_scene.exe --frames 3 --capture artifacts\xge-3d\scene.png
```

## 阴影与静态 IBL

方向光或聚光灯设置 casts_shadow=1，再把 `xge3dShadowDefault()` 的设置传给 render_desc.shadows；NULL 不执行阴影 Pass。每帧最多一个太阳、1～4 个级联及两个投影聚光灯；点光阴影会明确返回不支持。每张图分辨率、太阳距离、线性/对数分割比例、级联混合宽度、深度偏移、世界法线偏移、3×3 PCF 半径和深度余量均可配置。太阳以包围球拟合并对齐纹素，移动稳定；深度余量决定相机外光线方向上的遮挡物覆盖范围。聚光投影近面为 0.05 米，远面取光照范围，未设范围时取阴影距离。

Opaque 和 Mask 使用相同几何与 UV/Alpha 规则投影；Blend 当前不投影。统计 draw_calls 和 triangles 包含阴影 Pass，shadow_draw_calls 与 shadow_maps 单独给出。图集在首次使用或分辨率变化时创建，普通帧复用；没有阴影时不分配。静态网格、GPU 实例化（包括 Mask 与负缩放）、共享模型实例、独立动作驱动的蒙皮阴影以及混合 LOD 高度场的太阳/聚光阴影已验证。

IBL 为可裁剪静态扩展，用 `xge3dEnvironmentSetIBL` 复制漫反射六面、GGX 预过滤完整 mip 链和 BRDF LUT，再设置 render_desc.ibl_intensity>0。未提供数据却启用 IBL 会返回参数错误；强度为 0 时不上传 IBL 资源。金属、粗糙度和 AO 对间接光生效，unlit 不受灯光或 IBL 影响。替换数据失败保留旧环境；NULL 移除 IBL，天空保留。

当前预计算数据为线性 RGBA8，输入六面是 sRGB LDR；不支持 HDR 环境的亮度范围。C 离线工具生成 PNG，运行库不执行烘焙，不需要新二进制格式或工具依赖：

```bat
gcc -O2 -DXGE_DLL -include build/3d/xge_build_config.h tools/xge3d_ibl.c build/3d/xge.lib -lm -o build/3d/xge3d_ibl.exe
build\3d\xge3d_ibl.exe assets/env sky-px.png sky-nx.png sky-py.png sky-ny.png sky-pz.png sky-nz.png 64 128
```

最后两参数为预过滤基准边长（4～256 的二次幂）和样本数（16～4096）。输出 `env-irr-px.png` 等六面、`env-spec-0-px.png` 等各级六面及 `env-brdf.png`。漫反射输出已除以 pi；LUT 的 X 为 NdotV、Y 为粗糙度，R/G 为 Fresnel scale/bias。按普通图片读取，传入 SetIBL 后即可释放图片。离线工具和资源大小单独统计，不进入 DLL。

```bat
examples\xge_3d_lighting\build.bat
build\3d\xge_3d_lighting.exe --frames 3 --ibl --capture artifacts\xge-3d\lighting.png
```

此范例由应用修改太阳方向与曝光，可在主循环中接入自己的昼夜参数。

## 骨骼与独立动作

开启 `XGE3D_ENABLE_ANIMATION` 后，glTF Skin 保留源关节顺序和 inverse bind 矩阵，包括 sparse 矩阵。每个模型实例拥有独立姿态，网格、材质和动作可共享。每个 Skin 最多 256 个关节，`xge3dRendererMaxJoints` 返回当前 GPU 上限。每顶点保留最强四个影响并归一化；读取 JOINTS/WEIGHTS_0 与 _1，裁掉的顶点数由 ModelInfo.truncated_weight_vertices 报告。错误索引、负权重和全零权重会拒绝加载。蒙皮矩阵只在姿态变化后上传，主渲染与阴影共用。

`xge3dClipFromModel` 获取内置动作，`xge3dClipLoad` 独立加载包含骨架与动画的 glTF/GLB。Clip 复制轨道并持有源模型，支持 TRS 的 STEP、LINEAR、CUBICSPLINE，四元数线性路径使用最短弧插值。矩阵节点动画和 morph 轨道当前不支持。

```c
xge3d_clip *walk = NULL;
xge3d_animator *animator = NULL;
int result = xge3dClipLoad("assets/walk.gltf", 0, &walk);
if (result == XGE_OK) result = xge3dAnimatorCreate(scene, actor_root, &animator);
xge3d_animation_layer_t layer = xge3dAnimationLayerDefault();
if (result == XGE_OK) result = xge3dAnimatorSetLayer(animator, 0, walk, &layer);
xge3dClipFree(walk); /* Animator retains the clip. */
/* On each frame: xge3dAnimatorUpdate(animator, delta_seconds). */
```

Animator 借用场景，先释放 Animator 再释放 Scene。根节点或源骨骼被删除后 Update 返回 INVALID_STATE。两个覆盖层按 0、1 顺序对资产参考 TRS 混合；层 1 权重从 0 逐渐调至 1 可用于平滑切换。遮罩按目标模型源节点索引排列，数据会复制。自动绑定要求双方骨骼名称唯一；同一模型用源索引，显式 bindings 可以指定源/目标节点。运行时绑定仅适用于已经匹配的骨架，不修正不同参考姿态或骨长；不同人形骨架使用下面的离线工具。

`xge3dAnimatorBoneNode` 返回真实场景骨骼节点，应用把普通节点设为子节点即可建立武器、特效挂点。每层最多 1024 个按时间排序的事件，用 SetEvents 复制，NextEvent 消费。初次成功 Update 包含开始时刻，后续使用 `(old,new]`，循环时发出结束及新一轮零时刻事件。先排层 0 再排层 1；权重为零的层仍推进时间并发事件，应用按需要清除层。队列最多 4096 个未消费事件；超限 Update 失败且时间、场景姿态、根运动及已排事件保留。

`xge3dAnimatorSetRootMotion` 选择目标模型源节点及 X/Y/Z/旋转分量。选中分量从骨骼姿态中移除，`xge3dAnimatorTakeRootMotion` 取出并清空累计结果，循环边界保留完整位移。平移为该骨骼父坐标下的增量之和，旋转为累计四元数；双层结果按遮罩和层权重混合。应用将结果转换到角色坐标，完成自己的碰撞检查后移动实例。XGE 不自行移动角色或决定碰撞、角色控制规则。

## C 离线转换与人形重定向

```bat
python tools/build_3d_tools.py
build\3d-tools\xge3d_motion.exe list character.fbx
build\3d-tools\xge3d_motion.exe convert character.fbx walk.gltf --clip Walking_A --fps 30
build\3d-tools\xge3d_motion.exe convert mocap.bvh walk.gltf --unit 0.01 --up y
build\3d-tools\xge3d_motion.exe convert walk.gltf hero-walk.gltf --target hero.gltf --map bones.json
```

FBX 使用固定 ufbx，在工具内处理 Euler 顺序、参考变换及原文件单位/坐标，归一到米和右手 Y-up。BVH 保留源节点名称、层级、参考 offset 与旋转通道顺序；文件缺少单位约定，unit 为米/源单位（默认 0.01），up 可选 y/z。glTF/GLB 动作可再次采样或作为重定向输入。clip 支持名称或索引，start/end 按所选片段的相对秒数裁切，输出从 0 秒开始；fps 范围 1～240，默认 30，结尾保留精确时间，不生成重复浮点时间键。

输出是内嵌缓冲的单个 glTF 文件，保存源参考 TRS 和 LINEAR 动作轨道，可以直接 ClipLoad；文件通过 xrt 原子写入。每个骨架最多 2048 个源节点，姿态表上限 256 MiB、单片段最多一小时；超过限制明确失败。运行库没有 FBX/BVH 解析器、JSON 映射或重定向工具依赖。

映射使用 JSON，示例：

```json
{
  "bones": [
    {"semantic":"hips", "source":"pelvis", "target":"Hips"},
    {"semantic":"left_upper_arm", "source":"upperarm_l", "target":"LeftArm",
     "target_reference_rotation":[0,0,0,1]}
  ]
}
```

这段只展示格式；实际必须完整提供 hips、head、左右 upper/lower_arm、upper/lower_leg 和 foot。root、spine、chest、hand 等可继续映射。名称须唯一，重复、缺失语义和不存在的骨骼均有诊断。完整的已验证映射由 `test/make_3d_rigs.py` 生成在 fixtures 中。

默认以双方资产参考姿态计算世界旋转差，再还原到目标父节点坐标，从而处理局部轴差异。source_reference_rotation/target_reference_rotation 为局部参考四元数，可把不同 T/A 姿态校正到共同人形参考姿态。source_reference_time 可选择已采样源动作中的参考秒数。root/hips 保留位移，其他目标骨骼保留原骨长；translation=false 可以禁用指定根/骨盆位移，参考平移覆盖仅允许目标 root/hips。默认按参考 head 至双 foot 的 Y 高度比例修正位移，也可指定正的 translation_scale。

目前是显式映射的基础人形离线重定向，要求相关骨链为正的均匀缩放。目标模型的动画节点须采用 TRS；矩阵参考可在工具中读取，但运行时不会强行分解模型矩阵节点。没有自动语义识别、脚部 IK、接触锁定或运行时重定向；比例差异大时，脚部滑动或穿地需由动作制作或应用修正。工具不保证任意未知角色无需配置即可适配。

```bat
test\build_3d_suite.bat retarget 3d
examples\xge_3d_animation\build.bat
```

源素材、版本、许可证和哈希见 [动作测试资源](../test/assets/3d_motion/README.md)；两种目标的参考姿态、局部轴、比例与蒙皮有真实差异，输出可重复生成。
