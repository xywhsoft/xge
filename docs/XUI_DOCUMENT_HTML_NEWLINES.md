## 产品行为

HTML字面CR和CRLF在词法处理前转为LF；字符引用随后解码，所以`&#13;`产生的语义CR必须保留。导入器对正文及属性复用这一规则，导出器把语义CR写为`&#13;`。否则富文本中的CR经过HTML保存、重开会被改变。

pre开始标签后的首个LF字符token跳过一个，包含数值及命名引用产生的LF。首个token为code标签或注释时，后续LF保留；前导空格也阻止此删除。嵌套pre/code的出口保持代码内容开头LF。

规则依据[HTML输入预处理](https://html.spec.whatwg.org/multipage/parsing.html#preprocessing-the-input-stream)和[pre元素](https://html.spec.whatwg.org/multipage/grouping-content.html#the-pre-element)。这是当前片段导入器的针对性实现，不能据此宣称已实现完整浏览器HTML解析。
