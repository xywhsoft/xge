# 轻量 3D 交付与实测

执行范围来自 [落地方案](../plans/xge-3d/IMPLEMENTATION.md)，进度和验收入口见 [PROGRESS](../plans/xge-3d/PROGRESS.md)。公开接口、所有权和限制见 [3D C API](3D.md)，配置见 [构建说明](BUILD_PROFILES.md)。运行库新增实现采用 C，容器、文件和线程复用 xrt；没有新增 ECS、编辑器、游戏世界抽象或完整物理/导航后端。

## 启动

```bat
build_dll.bat 3d
test\build_3d_suite.bat all 3d
examples\xge_3d_integration\build.bat full-dev --run --frames 360 --capture artifacts/xge-3d/integration.png
```

综合范例使用公开 API，把模型、共享材质与静态实例、分块高度场、太阳/聚光阴影、天空、两种骨架的六类外部动作、预算加载与真实 XUI 组合运行。十五项异步资源全部完成后计帧。应用实际导出静态三角形、过滤可行走表面、完成地面射线查询并写回位置，验证创建、移动、删除和 1e9 全局坐标下的原点重定位；这些应用数据及规则不进入 XGE。

FBX/BVH 转换与人形映射由独立 C 工具处理，运行库消费标准 glTF/GLB。已固定版本和许可的 KayKit CC0 外部 FBX 六类动作，在两个实际不同的 T/A 参考姿态、局部轴及比例的目标骨架上验证。范例构建缺少资源时会执行生成入口，详见 [范例](../examples/xge_3d_integration/README.md)及 [素材与许可](../test/assets/3d_motion/README.md)。

## 体积与构建

2026-10-03，Windows x64、GCC 16.2.0、-O2，DLL 去符号后的实际文件大小：

| 配置 | 字节数 | 用途 |
| --- | ---: | --- |
| core | 672,176 | 基础窗口、输入、资源、GPU |
| 2d | 723,404 | 基础二维 |
| 完整 3d | 873,737 | 本期三维能力，约 853 KiB；关闭二维、音频和 XUI |
| 3d 基础几何 | 721,930 | 关闭全部七个三维子模块 |
| ui-min | 3,230,247 | 精简界面，文本成本为主 |
| full-dev | 8,466,461 | 所有旧能力与三维同时开启，开发验证配置 |
| 旧 default | 8,270,784 | 原有默认能力；本期未增加其体积 |

3d 相比 core 增加 201,561 B，低于本期 5 MiB 预算。单独关闭 MODEL/LIGHTING/SHADOW/IBL/ANIMATION/TERRAIN/ASYNC 后分别为 755,793 / 849,131 / 856,811 / 871,177 / 849,673 / 864,009 / 865,545 B。依赖模块会随父模块关闭，变化不是简单相加。

新增异步 TU 的单文件增量实测 0.59 s，其他十三个对象复用，热构建约 0.14 s；HarfBuzz 有共享缓存。此前冷构建基线、参数及差异见 PROGRESS，不把并行或缓存不同的条件当作严格提速倍数。

离线 motion 工具当前 1,126,325 B，IBL 工具 107,008 B，按实际生成文件统计；工具、ufbx、映射 JSON 与原始 FBX 不进入运行库。PE 静态导入为现有 Windows 系统/CRT 库；原生绘制还动态使用系统 OpenGL 及显卡驱动。full-dev 的既存 HarfBuzz 用 C++ 编译，本期新增代码与导入工具仍为 C，不能把历史依赖描述为全部纯 C。动态导入和实际源码列表保存在 build-report 与验收 JSON 中。

验收生成的 fixtures 目录共 94 个文件、1,984,722 B；外部 KayKit 目录共 3 个文件、20,661,059 B，其中原始 FBX 为 20,659,324 B，其余为许可与来源记录。它们独立保存在 `artifacts/xge-3d/`，不计入 DLL 体积，也不随运行库自动打包。

## 运行证据

Windows 10 19045、AMD Radeon RX 5700、AMD OpenGL 4.3 驱动 26.8.1。两种配置分别单独运行；固定相机/姿态、640×480、两级 1024 太阳图和一个聚光图，每种模式保留 64 个有效样本。CPU 时间为提交耗时，GPU 时间通过真实 elapsed query 测量主/阴影绘制，不能混为完整帧时间。

| 3d 固定场景 | 实际提交 | CPU 中位数 / p95 | GPU 中位数 / p95 |
| --- | ---: | ---: | ---: |
| 关闭裁剪和实例化 | 401 | 355.5 / 520 µs | 634.71 / 773.65 µs |
| 开启裁剪和实例化 | 74 | 152 / 178 µs | 465.39 / 580.84 µs |

资源压力各跑 1,200 轮、3,320 个记录帧：300 次立即取消、300 次纹理半途取消、300 次网格半途取消、300 次完整加载并创建/销毁两个临时动画实例。两种配置合计 600 次完整加载、1,200 个临时实例；连续切换六类动作、移动相机，并执行移动、删除和重定位。加载墙钟均值约 16.74 ms，包含轮询帧间隔及上传，不作为纯解析耗时。压力阶段 CPU 中位数/p95 为 3d 340/471 µs、full-dev 491/710 µs，包含应用几何查询和启用的 UI。

测量数组在基线前预分配；第 300～1,200 轮，两种配置 CRT 忙堆字节和块数均保持不变。进程私有内存包含驱动保留及缓存，最终相对第 100 轮分别减少约 7.09/11.59 MiB；峰值工作集约 98.4/102.4 MiB，含测试场景、采样存储和驱动，不能用 DLL 体积推断游戏内存。此循环未见持续的 CPU 资源增长，不保证任何资产规模或驱动下均无泄漏。

预算模型的 8,940 B 数据在 32 次提交后与同步输出逐字节一致；字节/操作额度共享，支持纹理行/像素、VBO/IBO 续传及 mip 完成。取消、过期句柄、超限失败和 GL 解包/PBO 状态恢复通过。时间额度在操作之间检查，属于软限制；首次渲染器、姿态、实例矩阵、阴影和目标资源的工作另行计量。

完整 3d/full-dev 套件、六种顶层 profile、八种子模块裁剪配置及 65 个 XUI 控件/服务开关通过。关闭功能同时检查实际 TU、声明、导出和运行；默认保留全部 5,232 个旧导出，十七种代表性旧结构尺寸/偏移一致，默认烟雾回归通过。

## 平台及能力边界

Windows 原生路径已实际运行；GL 3.3/GLES 3.0/WebGL2 为着色器和基础格式的设计目标。实测上下文报告 GL 4.3；其他原生平台、GLES 设备和浏览器尚未执行，不宣称已完成跨平台验收。浏览器的文件入口与线程配置尤其需要另行验证，可先关闭 ASYNC 使用应用提供的加载方式。

当前为八个可见直接光源、一个太阳最多四级和两个聚光阴影；点光阴影暂不支持。透明为基础对象排序。IBL 为离线线性 RGBA8，未支持 HDR 或实时 GI。蒙皮最多 256 关节、四个影响，基础双层覆盖与显式离线人形映射；没有任意骨架自动适配、复杂动画图、IK 或接触锁定。

高度场为固定块、有限 LOD 和裙边，粗细边界仍可能有台阶；不含动态编辑、洞穴、纹理混合或世界流式策略。场景遍历和基础空间查询采用线性路径，没有空间树。应用维持双精度全局位置、区域加载、碰撞解算、角色规则及导航；XGE 提供真实几何、变换、查询、资源与渲染支撑。建造、背包、生成、存档和联网属于游戏项目。
