## 实现

Rich与Markdown共用SetLink/QueryLink语义节点收集，完整图片、行内HTML和换行都参与；图片自身地址/标题与包围链接的地址/标题分开保存。Markdown字段修改共用LINK/IMAGE写入器，保留未改字段、分隔空白、标签格式、实体、代码、Unicode、容器前缀和原始行结束。

选区可以跨多个链接、不同旧URI/标题、文字与图片以及段落/引用/列表。投影来源通过解析器确认的CST绑定可见LINK，排除图片alt里的隐藏链接。CST经过排序和二分区间查询，已选归属使用索引去重，避免每个文本/转义片段再次全量扫描CST或线性搜索已选链接。该索引在当前命令内构建，未据此宣称全局更新已达次线性性能。

引用使用只转换标签后的引用后缀，保留标签与隐藏定义。自动链接改目标时转为显式链接，按显示文本转义原本可在自动链接中直写的标点，保持Unicode、电子邮件与显示内容。相同URI/标题的归属跳过；全部无变化时不增加版本、历史或脏状态。

各归属在原始坐标下倒序应用字段补丁，最后解析一次，与期望语义文档完整比较。部分归属或额外内容的误改不能通过比较。所有临时来源、语法和输出内存归事务所有，失败不发布；连续语义命令仍在共同Document草稿中工作，提交后保留单次撤销/重做。
