# Document 完整塑形结果的基础范围接口

更新：2026-10-02。此项属于整体重构设计的 R1 正确性工作，整体长期目标仍在进行。通用 WebView 保持 Windows 基础承载和其余平台预留；Document 私有公式、Mermaid、HTML 通道保留。

## 输入与所有权

`XUI_PROXY_VERSION` 升为 **16**，原生文档格式保持 **7**。应用、自定义代理和 DLL 一起重编译，没有旧请求兼容层。`XUI_PROXY_CAP_TEXT_RANGE` 表示共享文本接口支持先塑形完整均匀 item、再选择字形范围；`XUI_TEXT_SHAPE_RANGE` 启用这一请求。

`sText/iTextSize` 是完整均匀字体、字号、样式、语言、脚本和方向的输入，不是行子串。`iRangeStart/iRangeEnd` 是该输入内的 UTF-8 字节范围。`sContext` 仍表示周围段落，不能把不同字体的整个段落当作同一个字体输入塑形。输出文本长度、cluster、caret 和颜色范围均以选择起点为零。

可选 `pShape` 借用同一后端、字体和完整塑形输入的不可变持久结果，调用结束即停止借用，不转移所有权。调用者负责输入相同和生命周期；原生后端还检查类型、长度、字体及方向/塑形标志。未提供时，原生后端塑形完整输入并临时选择字形。范围的返回结果拥有自己的几何数组，可以不返回持久 paint，不让借用 paint 逃逸。

测量、塑形、`drawText`、`drawTextSpans` 和 `textDraw` 共用这一契约。非空范围切入不可拆的连字或包含强制换行时，在绘制前返回 UNSUPPORTED；空范围返回零宽、零 cluster/caret。没有范围能力或没有实际塑形回调时，公开塑形接口明确拒绝，不使用孤立字符测量模拟范围。

`pPaintSpans/iPaintSpanCount` 在范围输入上为基础 `drawText/textDraw` 提供同步借用的颜色区间。几何忽略颜色，但验证区间；不能与显式 `drawTextSpans` 参数同时提供。普通请求要求全部范围、借用和颜色字段为空。输入短描述、UTF-8 中间字节、乱序/重叠颜色、无效长度和缺失数组统一拒绝。

## Document 接入

普通共享 span 和完整 SHY 插入模式均可经基础文本接口选择完整 glyph。缓存范围回调仍可直接消费原所有者；删除一个或两个缓存回调后，基础接口使用同一所有者，保留 advance、字形、颜色和小数画笔位置。方向变化导致独立行塑形时，也保留该行结果供基础绘制借用。

没有持久 paint 的范围后端仍可重新塑形完整均匀输入。Document 保留相应几何和完整上下文，不把缺失 paint 当作缺失行高。非持久路径可能重复塑形完整输入，其大文档性能仍需验收。

含 SHY 且具备共同范围能力的长段落必须先确定完整标记模式再发布。原生范围几何通过二分查找定位 cluster/caret 起点，再复制所选部分，避免每行扫描整个持久几何数组。多 SHY 候选本身仍可能多次塑形整个 span，尚未证明满足整体性能指标。

仅有空间裁剪的着色会截断覆盖边界的抗锯齿像素。本次基础范围输入直接把颜色区间映射到原 glyph 字节坐标，左右/上下对齐只移动画笔，裁剪仍使用调用者原矩形，并恢复原 GPU clip。

## 验证边界

独立字体让后面的 SHY 经第二个 OpenType lookup 把前行 glyph 的 advance 从20变成46。正确结果必须拒绝前面的 SHY并保留后面的 SHY。旧封存 DLL 的公开无缓存探针退出1；当前公开探针得到16/0/12/20/6/12，行位置0/0/0/40/40/80，退出0。原 fixture 字体未改，新字体可独立重生成得到相同 SHA256。

原生四种配置的3040次完整 RGBA涵盖缓存、基础范围、仅 drawText、Rich整段/分色、Markdown VISUAL/SOURCE/LIVE、Greek LTR/RLO、Hebrew、改宽/颜色、源码位置、caret/hit、裁剪、小数X、释放 Document和35007字节长段落。新范围测试188次完整 RGBA覆盖完整/部分输入、fresh/borrowed、方向、颜色、对齐，以及28次两种文档配置的完整标记模式；无持久 paint也有独立配置。GDEF停点验证返回偏移重基准、连字内部拒绝和空范围。实际无HarfBuzz验证另有320次SHY像素和80次范围像素。

真实 memory-debug 验证 fresh/borrowed 范围的11/2个几何分配失败点，颜色映射两个分配失败点，无像素半成品、clip/live storage不变及重试。默认与基础范围的完整 Document失败扫描均覆盖后向影响模式；完整退出码、源码/DLL/字体指纹和发布套件结论保存到 `artifacts/xui-document-rebuild/validation-2026-10-02-text-range-final-state.json`，以该终态为最终验收依据。
