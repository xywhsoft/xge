# Document 定义语法的不可变存储基础

日期：2026-10-05。所属 K2/K4/E1。当前为隔离原型，尚未合入；采集、增量对齐、来源索引及编辑消费尚未接入，原整体目标保持 active。

## 当前实现

语法存储由同一 `doc_state` 持有；每个定义使用不可变记录数组，原范围相对定义起点，父子关系使用记录序号。记录包括作用域、块、行内、文本、标记、字段、缩进、换行和不透明范围。原字节继续由唯一 SourceStore 持有，不创建可写影子 Document、语义节点、NodeId 或独立历史。

私有写入器仅用于未发布解析状态或事务草稿：验证根作用域、父子包含、范围、保留位、类型、数量及整数溢出，再原子替换对应定义的存储；读取失败清空结果。当前采用按定义序号的稀疏有序查找。精确新记录与旧数组完全一致时不分配并共享原数组，不能仅用去缩进正文或定义值相等证明来源可复用。后续定义增删对齐仍需接入，不能把此存储结构视为已经满足规模更新门槛。

新增字段已进入 state clone/release、普通当前/历史/快照诊断，以及异步发布的差量和完整根遍历两条预计算路径。重解析归一化使用解析状态中的语法字段；普通解析器当前仍未启用采集，故该字段仍为空。

## 实际验证

独立显式存储夹具通过实际 SOURCE 事务发布，覆盖三定义逆序插入、原记录复制、快照共享、替换后旧快照不变、共同 Undo/Redo/savepoint、Document 释放后快照读取和全部回收。语法写入没有分配语义 NodeId。当前/历史/快照类别及实际分配器 live 字节一致。

真实 Prepare/Run/Publish 验证带非空语法的旧状态进入历史。另用白盒条件强制完整根遍历，运行后恢复精确捕获的所有权，再实际 Publish/Undo，验证第二条预计算路径。前文实际插入八字节后，三个定义原范围均移动八字节；检查新定义后手工转移夹具数组，验证相对记录和零分配共享。此手工转移不是生产增量对齐。

独立错误夹具验证根、父节点、包含范围、类型、保留位、缺失定义、参数与溢出拒绝。枚举写入器八个分配失败点、八个分配时取消点及预取消，旧数组、身份、版本、语义 NodeId 保持，临时分配完全释放。范围长度不匹配的旧记录读取返回 schema 错误并清空结果。

普通/碰撞 ASan/UBSan 覆盖基本存储及完整根遍历/相对移动两个驱动；Source、Store、Memory、Publish、Reconcile 五模块分析通过。既有隐藏语法、围栏容器边界和来源索引工作预算驱动继续通过。共 23 条全新命令实际退出 0，验证输入已精确归档。分别移除两条发布遍历或仅移除完整根遍历的两个负例均编译 0、运行 1，确实检出所有权错误。

证据：[隔离验收](D:GIT/xge/build/source-cst-storage-20261005/prototype-accepted-v5.json)。十项产品改动仅在隔离目录，根目录 209 项正式输入保持不变。
