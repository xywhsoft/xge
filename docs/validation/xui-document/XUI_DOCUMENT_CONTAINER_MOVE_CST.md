## 实际改动

候选位于 `E:/codex-builds/xge-document-container-move-20261007-v73-01a09446`，来源为已冻结 v69。相对计划中的 GL/光标/View 等 37 项基线，产品仍只改 `src/xui/document/xui_document_markdown_edit.c`，沿用统一 Document、SourceStore、语义意图、事务、快照和根历史，没有增加第二套可写文档或旧 API 包装。

- 列表、任务列表和脚注的首行开头归属于容器。移动段落时只交换解析器确认的首行与续行前缀，保留列表符号、任务大小写、脚注标签以及段落原文。
- 裸 `>` 后的列表标记若直接变为空格，会让引用解析器消费一个空格。v73 从原有续行段落取得解析器确认的实际前缀，解决这类嵌套边界。
- 跨父节点的段落移动使用持久 SourceStore 切片。引用与列表元数据定位每行需要改动的容器前缀；Tab 按解析器逻辑列拆分，正文、实体、行内标记、硬换行和原始行尾继续共享。
- EOF 段落进入内部位置时补必要的行尾/块间分隔。移动前后完整语义树必须等价；有序定义原拼写保护保留，只有明确编辑的脚注正文使用既有的脚注例外检查，其标签和其他定义继续受保护。
- 正文按 4096 字节块扫描并检查取消，不逐字节查询持久序列，也不临时复制整条长行；只为解析器需要的缩进前缀分配临时存储。
