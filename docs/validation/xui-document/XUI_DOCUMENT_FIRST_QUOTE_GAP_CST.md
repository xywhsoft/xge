## 修复方式

扩展同一个 `doc_markdown_container_gap_source_patch` 的根文档和引用首间隙计划。非空容器插入只新增一个段落，旧子节点 ID 与顺序保持。首间隙直接取解析器确认的下一个块所在物理行，保留原块来源；存在 BOM 时，插入位置在 BOM 之后。

首间隙不需要段落之前的分隔空行，必要空行只写在新段落与原块之间。根文档使用零宽度前缀，引用使用已有解析器前缀计划；共享 Tab、字面代码、原围栏和信息字段保持。

只有首行和续行容器前缀原字节相同，才在这一计划中直接复用物理行边界。首行列表或脚注标记需要移动时仍返回未找到，由其他既有命令策略处理；该来源保真缺口仍待补齐。候选继续完整重解析、比较全部节点/属性/资源，并保护定义拼写。没有放宽语义、TIGHT、失败原子性或来源断言。
