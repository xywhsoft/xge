# Document 定义语法采集

日期：2026-10-05。所属 K2/K4。隔离原型完成本批验收，尚未合入正式产品；完整 CST、来源索引消费、其他编辑及原 13 工作包继续。

解析器在原有解析过程中采集可见、未使用及重复脚注定义的块、行内、文本、字段、标记、缩进、表格和换行记录。可见脚注复用原语义解析，隐藏脚注使用解析器的语法回调；不创建第二个 Document、第二份 SourceStore、额外语义 NodeId 或独立历史。记录进入同一 doc_state 的不可变定义语法存储。

未使用脚注正文的增量路径同步替换语法数组；正文中有引用查找时进入现有全局依赖更新，避免独立片段的引用环境改变解析。定义范围相同或去缩进正文相同，均不能单独证明旧来源记录可以复用。

实际验证包括 270 个加载、原生序列化重载及快照生命周期场景，覆盖三方言、三种换行与 BOM；565 个合法 UTF-8 源码位置的插入与完整重解析记录等价；316 个加载 OOM、306 个 Prepare/Run OOM 和 306 个分配时取消点，已有非空记录、源码、身份、版本、保存点和历史保持原子，所有分配回收。

可见结果与原未启用采集的解析器逐字节比较：270 场景、128847 字节的 HTML、原生文档、语义节点数量、下一 NodeId、普通行内语法、定义及候选完全相同。普通与强制散列碰撞 ASan/UBSan、三模块分析、无 hook 编译、既有隐藏语法及来源索引预算回归通过；最终 31 条命令实际退出 0，220 项验证输入精确归档。

独立字段范围检查曾检出围栏尾段被误记为字段，其内容范围无效；保留编译 0/运行 1 的失败证据，修正为语法标记，并保留解析器确认的 info/language 字段。修正后的全部最终验证已重新运行。
