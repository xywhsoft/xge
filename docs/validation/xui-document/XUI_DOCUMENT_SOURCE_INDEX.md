## 模型与实现

新增SourceIndex是同一Document快照的只读派生索引。它保留原快照，不复制SourceStore，不建立可写内容、另一份Document或撤销历史，创建时也不重新解析。v9正式新增十个公开接口，当前Document核心与UI共294接口；v3/v5的292接口是历史隔离候选。原有公开结构布局和原生格式保持。

索引记录统一组织语义来源范围、解析器确认的行内语法及字段、隐藏引用定义和未解析引用候选。记录使用索引内父子关系，保留语义NodeId及原来源条目序号；脚注等来源树位置与语义投影位置不同的情况按源码包含关系处理。

解析器确认的文本来源、块标记、引用/列表/代码缩进、表格分隔、换行、链接/图片字段进入统一注释集合。排序扫描后生成连续、不重叠的原字节Token序列；剩余空白、换行和BOM有明确类别及归属。结构语法内部的空白单独分类；有语义意义的正文、代码和字段空白保持内容类别。

Token保留完整解码来源区间。DIRECT片段按Token范围收窄文字偏移；实体、转义和归一化片段保留原映射区间及部分片段标志。偏移查询使用二分查找；源码读取直接访问被保留的SourceStore，支持调用者释放Document和快照后继续读取。

所有索引和临时存储经Document分配器分配，计入现有OtherBytes诊断。默认工作分配峰值上限64 MiB，可由调用者调整；包含扩容时旧、新缓冲同时存活的实际峰值。构建过程支持合作取消，排序、收集和扫描均有检查点。失败不会发布部分索引。
