直接 `xuiDocumentTxnSplitListItem` 原先会把快捷、折叠或完整引用改写为内联链接，将 `__` 粗体改为 `**`，并重写相邻实体、代码分隔符和链接标题引号。脚注正文中的三类引用还会返回 `UNREPRESENTABLE`。原十二场景诊断保留在 `build/source-document-footnote-local-reference-20261006/list-split-diagnostic-v1-proof.json`。

列表写在脚注定义首行时，共享段落前缀写入器还会遗漏 `[^label]:` 的续行转换，导致拆分退回整个脚注序列化。补上该前缀后，Tab 测试进一步发现，使用物理源码列计算列表宽度会受到脚注标签长度影响：多行内容被多加缩进，有序项可能被拒绝。

## 实现

所有变化仍在同一 Document、SourceStore、事务和历史中，没有新增模型或公开 API。

- 列表拆分复用段落拆分的 `doc_md_inline_split_wrappers`，由解析器确定格式、代码和链接包裹链；新边界只插入必要的关闭、列表标记和重新打开语法。
- 快捷与折叠引用转为使用原解析器选中定义的显式引用，保留定义本身、链接值和其他源码。
- 有序标记宽度变化时，只修改解析器确认的续行缩进；隐式引用的原关闭位置通过实际 SOURCE 操作重定位。
- 共享前缀写入器从现有脚注定义标签范围确认首行头部，将其转为四个续行空格，保留原首行头部。
- 原列表宽度使用解析器保存的首行逻辑列；新标记、Tab 和任务框间隔在同一逻辑列中计算。脚注正文的去缩进不受物理标签长度影响。
- 私有候选完整重解析，与整个预期语义树及定义保护检查一致后才交给原事务。失败不发布内容，沿用事务错误锁定、快照、撤销和重做机制。

非精确文字来源、GAP 和其他尚未证明的结构继续由原有受语义核对约束的路径处理；本批不声称这些路径都已无损。
