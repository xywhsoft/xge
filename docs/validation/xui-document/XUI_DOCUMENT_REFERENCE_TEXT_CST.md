## 行为与实现

编辑 `[abcd]` 或 `[abcd][]` 的显示标签时，原来的标签也是隐式引用键。直接把显示文本改成 `abEcd` 会丢失已选中的定义。CST 来源计划取得解析器实际选中的定义标签，把使用处改为 `[abEcd][abcd]`；原始定义、重复定义次序、目标、标题引号及旁边的 `&amp;` 不受影响。

普通 `ReplaceText` 在已建立完整期望语义后调用私有 `doc_markdown_text_source_patch`，复用已有的范围来源计划。该入口保持 `ReplaceText` 的原有换行语义，当前新路径只处理不包含 CR/LF 的输入和删除。`ReplaceRange` 的换行、段落拆分由父隐式引用拆分候选处理。

共用范围计划允许 Text 的容器为 Paragraph、Heading 或 Cell，并在普通链接编辑时保留外层 CST 包裹链。隐式引用的后缀补丁先应用，随后应用显示文本补丁；原始坐标经过统一事务更新。完整标签或一个独占格式片段删除时，仅删除其拥有的包裹语法。必要的段首语义空格用最小实体表示，避免解析器吞掉该空格；其他实体保持原拼写。

最终候选仍通过私有完整重解析和期望语义比较后发布。明确引用和直接链接在不改变归属时保留原有增量路径；其对照场景保持定义键、URI 和标题引号。源码计划不可表达时，原有受校验的回退与失败原子边界继续生效。
