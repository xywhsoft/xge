# 普通正文 CST 的统一公开来源索引

更新：2026-10-06。状态：隔离候选已通过公开黄金、来源回归、完整索引差分与官方语料检查；完整依赖正常 DLL 已验证；Linux/Windows 常规 CST 入口正在验证，尚未合入。整体重构和 K2 工作包未完成。

## 实现

同一 Document 快照中的 `source_syntax` 保存普通正文语法，`reference_syntax` 保存定义语法。两者共用一个来源索引投影器，进入现有 `xuiDocumentSnapshotCreateSourceIndex` 派生的索引，不增加另一套 Document、语义 NodeId、源码副本或产品解析调用。

新增 `XUI_DOC_SOURCE_RECORD_SYNTAX_DOCUMENT` 标志区分普通正文 SYNTAX 记录。记录的 `iOriginIndex` 是该快照内按源码排序的正文 arena 序号；`XUI_DOC_SOURCE_BINDING_DOCUMENT_SYNTAX` 绑定的 `iOriginIndex` 是 arena 内语法记录序号。定义来源继续使用自己的定义序号。两类来源均通过保留的不可变快照读取。

公开记录保留原始范围、字段内容范围、父子关系和语法标志；绑定保留解析器确认范围、容器逻辑列、表格位置和零长度锚点。普通正文语法记录不伪装成语义节点：`iNodeId` 为零，绑定带 `SOURCE_ONLY`，文本偏移为 `UINT64_MAX`。已有语义来源绑定仍在同一索引中提供节点和文本位置映射。

字节分区继续覆盖每个原字节。普通文字、标题正文和未解析引用候选的语法绑定不覆盖已有语义文本来源。front matter 内容始终是不透明载荷，其中的 `<!-- ... -->` 不被误分类为 HTML 注释。正文和定义的字段、标记、缩进等由相同投影实现处理。
