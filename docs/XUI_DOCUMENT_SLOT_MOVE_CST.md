2026-10-07 独立 v89 已完成本文件所列专项验收。六个新原始失败场景已修复，产品与永久测试包尚未合入；整体重构和原 11 个工作包继续执行。

## 实现

候选位于 `E:/codex-builds/xge-document-slot-move-20261007-v89-01a09446`，来源为独立 v86，继续复用一个 Document、持久 SourceStore、不可变快照、统一事务与根历史，没有新建第二套文档或旧 API 包装。

相对计划中的 GL/光标/View 等 37 项基线，共改六个产品文件和一份依赖说明：`src/xui_document_markdown_edit.c`、`src/xui_document_markdown.c`、`src/xui_document_internal.h`、`src/xui_document_md4c.c`、`src/xui_document_md4c.h`、`lib/md4c/md4c.c` 与 `lib/md4c/README.xui.md`。

- 列表、任务标记和脚注标签属于容器。首段移出时把原标记交给第一个存活段落；新段落插入首位时承接原标记，原首段改用实际续行前缀。正文、实体、格式开头、任务大小写和标签原字节保持。
- 为脚注增加私有 parser hook。统一解析器把实际去缩进的每行范围写入同一状态的相对元数据与 CST；隐藏定义也收集 CST，不新增可写语义文档。移动写入器不从标签长度或正文位置猜测四列缩进，懒续行沿用解析器的真实决定。
- 持久序列只切分、搬移正文，生成需要变化的容器前缀。首行、普通续行与空行分别处理；外部两个首行前缀先映射到搬移后坐标，再按从右到左顺序修补。源码开括号计数和来源存储计数随前缀更新。
- 跨两个脚注移动只允许这两个已确认的正文范围变化。各标签前缀、所有其他有序定义和其中的链接定义继续原拼写核对；完整解析与语义投影仍是发布前条件。
- 列表的派生松紧属性只在受移动影响的两个原祖先链上独立规划。完整树、其他属性与定义必须通过保护，属性操作和移动进入共同历史。定义保护先于属性计划，失败候选不会改变回退使用的语义意图。
- 根的脚注显示顺序与物理定义位置可以不同。根段落范围使用实际块尾与随后的空行，不把显示列表中随后出现的脚注误作物理后继，也不搬走下一条隐藏定义。

## 失败记录

原 v84 六例检出三处原字节/历史差异和三次拒绝，完整输出保留。v85 新 hook 和前缀搬移消除原字节差异后仍有三次拒绝；私有对照确认两例涉及列表派生属性，另一例涉及根的脚注显示顺序。v86 修复并在四配置通过原断言；v89 再固定定义保护先于派生属性计划。

初次 Windows 工作入口把相对测试路径交给独立目录里的编译器，29 个单元已编译但测试未启动；后续使用新目录和绝对路径。完整 Core 的第一次记录器共用平台文件名，碰撞配置原产品已通过但写终态失败；故障入口第一次读取了缺少旧矩阵字段的短报告。实际库入口第一次把保护文件列表错误加入一个链接命令，产生重复 main。所有原控制器的退出 1、日志与输入保留，新独立入口只修正路径、报告选择及测试入口构造，原产品 C 和断言不改。

最终限定终态记录器初次误认为普通和碰撞扫描点数相同，写终态前失败；新记录器逐行核对实际故障数据，分别记录 31,592 与 31,596，没有改写产品结果。
