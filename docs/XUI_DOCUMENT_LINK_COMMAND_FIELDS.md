## 实现与行为

已有链接的 URI、标题和联合修改现在复用图片的字段写入器。目标和标题范围来自解析器确认的 CST；未修改的字段、标签原始格式、转义、实体、Unicode、容器前缀、行结束和分隔空白保留。无标题时在目标 token 后插入；遗漏空目标仍以 `<>` 明确写入。合法 CR/LF 标题写成实体，保留所请求的语义值。

命令使用与 SetLink、QueryLink 相同的语义节点收集来确定来源范围。段落 GAP 选区使用所选行内节点的来源，避免把下一兄弟的语法或整个段落的近似位置当作字段归属。CST 父子关系排除外层图片 alt 内的隐藏链接。来源范围仅用于提名链接归属，完整重解析与期望语义树比较才决定是否接受；部分文字选区不能因此误改整个链接。

完整引用链接使用位置转换为行内目标，保留原标签和隐藏定义。无变化命令不增加 revision、历史或脏状态。连续修改共用事务草稿，提交后可一次撤销和重做。

统一语义命令纳入完整图片、行内 HTML、soft/hard break。图片链接修改使用独立的 `link_target/link_title`，保留图片自己的资源地址、标题与 alt；部分图片 payload 选区拒绝并保持事务原子。Rich 与 Markdown 共用这条语义路径；没有增加公开 API，也没有兼容包装。三个公开头文件字节与父批次一致，ABI16、原生格式7保持。
