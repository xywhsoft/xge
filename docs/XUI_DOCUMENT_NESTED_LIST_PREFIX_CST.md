## 已确认的问题

从根段落内部删除到深层列表中的引用段落末尾，未选中的隐藏链接定义、列表祖先、空引用和根尾部仍需保留。删除外层列表段落正文时，`doc_md_removed_item_paragraph_body` 只读取最多 256 字节的来源前缀。53 层列表的被删除段落具有 260 字节前缀，截断后不能识别完整标记，最终无法证明编辑结果，合法命令被拒绝。

独立输入使用 `+    ` 和 `1.   ` 两种合法五字节标记，深度为 1/2/8/16/23/24/25/26/32/48/50/51/52/53/54/60。每个输入与独立预期文档均确认实际 List/ListItem 祖先、引用结构、精确 TEXT 来源映射和一条实际隐藏定义；不依赖字符串拼写推定语法成立。完整矩阵包含 LF/CRLF/CR、BOM、EOF 换行和正反选区，共 768 场景。

v355 的两端实际默认共享库各完整执行 768 场景，均拒绝 144 个，成功编辑零原字节差异。32 场景边界矩阵中，53/54/60 层的两种标记共拒绝六个。失败仍保持内容、版本、保存点和历史原子。

早期探针中的打印编译错误、无效有序列表嵌套、空列表被合法删除的错误预期，以及缺少空行而未成为隐藏定义的来源，都保留原失败记录；不计入上述有效产品负例或验收。
