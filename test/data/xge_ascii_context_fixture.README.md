# ASCII contextual paint fixture

`xge_ascii_context_fixture.ttf` is generated by
`test/generate_ascii_context_fixture.py` with FontTools. Its rectangular outlines,
cmap and OpenType rules are project-owned; it contains no external font outlines.
The generator fixes timestamps and produces deterministic bytes.

At 40 px, shaping `a b` together substitutes `a.context` (32 px) and `b.context`
(36 px). Shaping the two row strings `a ` and `b` separately produces the normal
16 px and 12 px glyphs. The space is 10 px. The `calt` rules exercise both GSUB
lookahead and backtrack; a separate `fi` ligature exercises range-cut rejection.

Every nonzero glyph index has a literal PUA alias at U+E400 + index. GPU tests
draw U+E404 / U+E405 / U+E408 as independent reference glyphs, without shaping
the contextual source substring. This is a targeted cache/draw consistency
oracle, not a claim of browser layout conformance or general font coverage.
