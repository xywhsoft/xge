# XGE script fixtures

These project-owned fonts are generated by `test/generate_script_fixture.py`.
No operating-system or external font is copied. FontTools is a generation-time
dependency only. Fixed timestamps make regeneration deterministic.

`xge_script_fixture.ttf` has Latin/Greek parenthesis `locl` substitutions,
a Kana-only long-sound-mark substitution, and a Syriac-only Tatweel
substitution. OpenType uses the `kana` script tag for both Hiragana and Katakana.
The differing outlines and advances make wrong script selection observable in
actual glyph output and layout; these are test glyphs, not production fonts.
Private-use cmap aliases address the exact expected glyphs directly for an
independent GPU alpha oracle, bypassing all script-specific substitutions.

`xge_script_no_alaph.ttf` removes only the Alaph cmap entry. Its glyphs and layout
tables remain identical. A complete Syriac word containing Arabic-primary
U+0640 must select the complete fallback font and its Syriac substitution.

`xge_script_probe_tatweel.ttf` removes the Tatweel cmap entry and adds a
Syriac-only `.notdef` substitution. This deliberately artificial test font
requires actual GSUB coverage probing with the resolved Script_Extensions:
Tatweel followed by Alaph must keep the primary font, even though the first
character's primary Script is Arabic and its nominal cmap lookup fails.

The Unicode property data comes from the pinned Unicode 17 files listed in
`src/xge_unicode_script_data.inc`, under `lib/unicode/LICENSE`. Property and
run resolution tests are separate from these font fixtures.
