# XGE context fixtures

These project-owned fonts are generated by `test/generate_context_fixture.py`.
No external font bytes are copied. FontTools is only needed to regenerate them;
the timestamps and resulting bytes are deterministic.

`xge_context_fixture.ttf` gives Arabic Beh visibly different isolated, initial,
medial and final glyphs and advances. A Fatha mark has a real GPOS anchor.
Latin `locl` has separate default, English and Turkish glyphs. Syriac `locl`
changes Arabic-primary Tatweel. Private-use aliases address every test glyph.
These outlines are fixtures, not a production typeface.

`xge_context_probe.ttf` removes the Beh and i cmap entries. Context-specific
Arabic forms and Turkish `locl` deliberately substitute `.notdef`. Other
languages and isolated Arabic must use a complete fallback font. This verifies
that real GSUB coverage probing receives the same context and properties as
final shaping, including rebasing absolute context clusters to item offsets.

`test/test_context_shaping.c` uses upstream HarfBuzz with independently supplied
known scripts as its glyph, advance and GPOS oracle; it does not reuse XGE's
Script_Extensions resolver or coverage helper. Literal glyph checks additionally
make Arabic forms and language selection observable.

`xge_context_medi_probe.ttf` removes only Beh's cmap and substitutes `.notdef`
only in `medi`. Unlike the general probe, an incorrectly selected `init` or
`fina` really fails coverage and chooses the complete fallback. This makes
long transparent-context item coverage errors observable. The real C fallback
portability test checks that coverage directly even with 512 preceding marks.
The complete-word selector prefers the full font when the probe cannot cover
the word's init/fina edges. If unmapped acute marks prevent both fonts covering
the word, local grapheme fallback can still choose the medial probe. Its
deterministic SHA256 is
`ceb0c5bf22e3fea8e51254c9462e4bd4464d175cab192b5be2b98526194aeea8`.

`test/test_joining_context.c` shapes the complete paragraph in the independent
HB oracle, then checks the item's base glyph and positions. It never uses HB's
bounded item-context API as the reference. Counts around the five-scalar
window and up to 512 marks, both sides, format/supplementary transparent
characters and ZWJ/ZWNJ/space barriers are covered. Whole-paragraph equality
uses Arabic's resolved RTL direction; explicit LTR remains covered by the
separate upstream bounded-item oracle. These fixtures are not a real-world
font or all-script conformance matrix.
