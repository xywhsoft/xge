# ASCII paragraph script fixture

Generated by `test/generate_ascii_script_fixture.py`, optionally taking an output
path. Rectangles, cmap and OpenType rules are project-owned; no OS font outlines
are copied. Fixed timestamps make the serialized font reproducible.

The DFLT script substitutes parentheses with glyphs 5/6, advance 200 units.
The latn script uses glyphs 7/8, advance 300 units. The Latin `a` is glyph 2,
advance 600 units. At 40 px `(a)` must therefore total 48 px, even when separate
font items own each character. A Common-only `()` totals 16 px. Literal aliases
at U+E500 + glyph index let GPU tests draw independent reference outlines.

This exercises paragraph script resolution and input propagation. It does not
prove arbitrary GSUB lookahead across font boundaries or whole-word font choice.
